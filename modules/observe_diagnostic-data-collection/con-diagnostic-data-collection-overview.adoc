= Diagnostic data collection overview

[role="_abstract"]
When you cannot resolve {product-very-short} deployment issues independently, collect diagnostic data with the must-gather tool to help {company-name} Support investigate your support case.

include::../../artifacts/snip-technology-preview.adoc[]

The must-gather tool collects deployment configuration, resource states, logs, and runtime information from the {product-very-short} instances running in your cluster.

*Supported platforms*

{ocp-short}::
Run `oc adm must-gather` with the {product-very-short} must-gather image.

Kubernetes::
Run the must-gather Helm chart.

*When to collect diagnostic data*

* Opening a support ticket with {company-name} Global Support Services
* Troubleshooting deployment issues
* Capturing deployment state before {product-very-short} upgrades

[NOTE]
====
Collection size ranges from a few MB for basic collections to several GB when including heap dumps.
Plan for adequate storage and bandwidth.
====

[IMPORTANT]
====
The must-gather output might contain sensitive information such as configuration values, environment variables, application logs, and resource definitions.
Review the output before sharing it with support.
====
