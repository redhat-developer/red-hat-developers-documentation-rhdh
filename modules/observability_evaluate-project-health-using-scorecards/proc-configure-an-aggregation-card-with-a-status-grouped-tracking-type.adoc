= Configure an aggregation card with a status-grouped tracking type

[role="_abstract"]
Configure a scorecard aggregation card to count entities based on status thresholds.

The following steps configure the card on a read-only home page. On a customizable home page, you do not define a `widgetLayout` section; instead, you add the card from the user interface and set its aggregation ID. For more information, see {scorecard-plugin-book-link}#configure-portfolio-health-on-a-customizable-home-page_configure-portfolio-health[Configure on a customizable home page].

.Prerequisites

* The scorecard plugin is installed and configured in your {product} instance.
* You configured the dynamic home page layout and registered the aggregated Scorecard card in the `homepage.defaultWidgets` section. For more information, see {scorecard-plugin-book-link}#configure-a-default-scorecard-aggregation-card_configure-aggregated-scorecard-kpis[Configure a default scorecard aggregation card].

.Procedure
. Open your `{my-app-config-file}` file.

. Go to the `scorecard` section and define your backend key performance indicator (KPI) map within an `aggregationKPIs` block, setting the tracking type to `statusGrouped`:
+
[source,yaml]
----
scorecard:
  aggregationKPIs:
    teamAlphaBugs:
      title: "Team Alpha Bug KPI"
      description: "Portfolio bug counts grouped by status threshold"
      type: statusGrouped
      metricId: jira.openIssues
----

. In the `app.extensions` section, reference your custom aggregation ID in the `aggregationId` property of the aggregation card under the `widgetLayout` section of the dynamic home page layout:
+
[source,yaml]
----
app:
  extensions:
    - home-page-layout:homepage/dynamic-homepage-layout:
        config:
          customizable: false
          widgetLayout:
            scorecard-aggregated-card:
              - id: ScorecardTeamAlphaBugs
                props:
                  aggregationId: teamAlphaBugs
                priority: 410
                breakpoints:
                  xl: { w: 4, h: 6, x: 0, y: 0 }
                  lg: { w: 4, h: 6, x: 0, y: 0 }
                  md: { w: 6, h: 6, x: 0, y: 0 }
                  sm: { w: 6, h: 6, x: 0, y: 0 }
                  xs: { w: 12, h: 6, x: 0, y: 0 }
                  xxs: { w: 12, h: 6, x: 0, y: 0 }
----

. Save the modified configuration file and restart your {product} instance.

.Verification
. Access your {product-short} homepage interface.
. Verify that the status-grouped scorecard summary card displays with your defined title and calculations.
