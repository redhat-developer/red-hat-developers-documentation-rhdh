= Scorecard metric group configuration parameters

include::{docdir}/artifacts/snip-technology-preview.adoc[]

[role="_abstract"]
Parameters for the `scorecard-layout:scorecard/scorecard-entity-layout-grid` extension, used to group Scorecard metrics into grid cards.

== Extension configuration properties
[cols="1,3", options="header"]
|===
|Property |Description
|`disabled` |Set to `true` to turn off the grouped grid layout and revert to the default one-card-per-metric view. Defaults to `false`.
|`config.groups` |A map of group definitions. Each key is a unique group identifier used internally; it is not displayed in the UI.
|===

== Group configuration properties (`config.groups.<group-id>`)
[cols="1,1,3", options="header"]
|===
|Property |Required |Description
|`title` |Yes |The display name rendered on the group's card header. Used when `titleKey` is omitted or has no translation.
|`titleKey` |No |A translation key for the group title. When it resolves, it replaces `title`.
|`description` |No |Short text describing the group, rendered below the title. Used when `descriptionKey` is omitted or has no translation.
|`descriptionKey` |No |A translation key for the group description. When it resolves, it replaces `description`.
|`metrics` |Yes |An array of metric IDs to include in the group, in display order. For valid metric IDs, see xref:available-scorecard-metric-providers-and-metric-ids_{scorecard-ref-context}[Supported Scorecard metric providers].
|===
