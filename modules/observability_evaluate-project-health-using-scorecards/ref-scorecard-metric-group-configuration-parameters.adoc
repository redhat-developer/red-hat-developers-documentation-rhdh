= Scorecard metric group configuration parameters

include::{docdir}/artifacts/snip-technology-preview.adoc[]

[role="_abstract"]
Parameters for the `scorecard-layout:catalog/scorecard-entity-layout-grid` extension, used to group Scorecard metrics into grid cards.

== Extension configuration properties
[cols="1,3", options="header"]
|===
|Property |Description
|`disabled` |Set to `true` to turn off the grouped grid layout and revert to the default one-card-per-metric view. Defaults to `false`.
|`config.groups` |A map of group definitions. Each key is a unique group identifier used internally; it is not displayed in the UI.
|===

== Group configuration properties (`config.groups.<group-id>`)
[cols="1,3", options="header"]
|===
|Property |Description
|`title` |The display name rendered on the group's card header.
|`description` |Optional short text describing the group, rendered below the title.
|`metrics` |An array of metric IDs to include in the group. For valid metric IDs, see the table in Supported Scorecard metric providers.
|===
