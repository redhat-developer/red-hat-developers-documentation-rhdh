= Scorecard metric grouping

include::{docdir}/artifacts/snip-technology-preview.adoc[]

[role="_abstract"]
Group related Scorecard metrics into categories so you can scan a component's health by topic instead of reviewing one card per metric.

By default, the Scorecard plugin renders one card per metric on a component's *Scorecard* tab. On components with 10 or more metrics configured, this flat layout becomes cluttered and hard to scan. Metric grouping lets you combine related metrics, such as all the security checks for a component, into a single grid card.

A grouped card displays a tile for each threshold status (for example, `Critical`, `Warning`, or `Passed`) with a count of the metrics in that status. You can view the underlying data sources for a group in two ways: selecting a status tile opens a dialog already filtered to that status, while selecting *View data sources* from the card's *More options* menu opens the same dialog listing every metric in the group. Either way, the dialog shows the plugin, check, value, status, and last synced time for each metric.

A metric that you assign to a group no longer also renders as an individual card. Metrics that you do not assign to any group continue to render as individual cards alongside your grouped cards. A group is hidden entirely if none of its metrics are available for a given component.

This grouped grid layout is available only on the New Frontend System (NFS). On the Old Frontend System (OFS), group cards are not rendered.
