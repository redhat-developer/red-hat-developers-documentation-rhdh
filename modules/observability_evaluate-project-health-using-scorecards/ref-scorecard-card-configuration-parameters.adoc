= Scorecard card configuration parameters

[role="_abstract"]
Parameters for application settings and dynamic plugin files used to manage homepage visualizations and portfolio data logic.

== Dynamic plugin properties
[cols="1,3",options="header"]
|===
|Property |Description
|`aggregationId` |The target identifier for the homepage visualization block. Accepts a default system metric name string or a custom KPI key mapped in your core settings.
|`metricId` |[Deprecated] Legacy identifier for the source metric string. Supported for backwards compatibility but scheduled for removal in a future release. Replace with `aggregationId`.
|===

== Application configuration properties (`scorecard.aggregationKPIs`)
[cols="1,3",options="header"]
|===
|Property |Description
|`title` |The primary textual label rendered on the header block of the homepage card.
|`description` |A brief text string summarizing the target scope of the KPI.
|`type` |The aggregation algorithm. Specify `statusGrouped` or `weightedStatusScore` to summarize entities by threshold status, or one of the scalar types (`sum`, `average`, `max`, `min`, `count`) to roll up a single numeric metric. See "Supported aggregation types" for details.
|`metricId` |The unique provider identifier mapping to the individual source plugin collection layer.
|`filter.status` |Optional. Scalar types only. Restricts the calculation to entities whose latest threshold evaluation matches the given status key. Silently ignored on `statusGrouped` and `weightedStatusScore`.
|===

[IMPORTANT]
====
The `weightedStatusScore` type was previously named `average`. Deployments with `type: average` configured for a weighted portfolio score must update to `type: weightedStatusScore`, otherwise the backend fails startup validation. The `average` type now refers to the scalar aggregation described in this table.
====

== Options parameters for the `weightedStatusScore` tracking type
`options.statusScores`:: Map of threshold status rule keys (`success`, `warning`, `error`) to numeric weight integers. This parameter is required for the `weightedStatusScore` type and must be non-empty; missing or empty maps cause application startup failures.
`options.thresholds`:: Optional numeric value array tracking custom status levels evaluated against the weighted score output value on a scale from 0 to 100 with one decimal place. If omitted, the system falls back to default values: less than 30 indicates an error, 30 to 79 indicates a warning, and 80 or higher indicates a success. Custom configurations must provide full real-line range coverage with no numeric gaps.

== Options parameters for scalar tracking types
`filter.status`:: Optional. Threshold status key (case-sensitive) that must match a threshold rule for `metricId`. Only the latest entities with that status contribute to the aggregated value.
`options.thresholds`:: Optional. Classifies the aggregated scalar output using the same threshold rule syntax as metric thresholds. If omitted, the aggregated value is returned without a status classification.
