= Enable Scorecards

[role="_abstract"]
To monitor component health and quality in {product-very-short}, you must enable the Scorecard plugin in your configuration.

.Prerequisites
* You have {configuring-book-link}[added a custom {product-short} application configuration].

.Procedure

* Add the following configuration in your {product-very-short} `dynamic-plugin-config.yaml` file:
+
[source,yaml]
----
plugins:
  - package: oci://ghcr.io/redhat-developer/rhdh-plugin-export-overlays/red-hat-developer-hub-backstage-plugin-scorecard:<tag>
    enabled: true
  - package: oci://ghcr.io/redhat-developer/rhdh-plugin-export-overlays/red-hat-developer-hub-backstage-plugin-scorecard-backend:<tag>
    enabled: true
----
