= Configure a default scorecard aggregation card

[role="_abstract"]
Add a standard scorecard summary card to your homepage by using a metric ID directly as its aggregation ID.

.Prerequisites

* The scorecard plugin is installed and configured in your {product} instance.

* You have administrator permissions to update application configuration files.

.Procedure
. Open your `{my-app-config-file}` file.

. In the `app.extensions` section, define the aggregation card under the `widgetLayout` section of the dynamic home page layout, and set the `aggregationId` property to a metric ID, such as `github.openPRs`:
+
[source,yaml]
----
app:
  extensions:
    - page:home: false
    - page:homepage:
        config:
          path: /
          title: Home
    - api:home/visits: true
    - app-root-element:home/visit-listener: true
    - home-page-layout:homepage/dynamic-homepage-layout:
        config:
          customizable: false
          widgetLayout:
            scorecard-aggregated-card:
              - id: ScorecardGithubOpenPRs
                props:
                  aggregationId: github.openPRs
                priority: 410
                breakpoints:
                  xl: { w: 4, h: 6, x: 0, y: 0 }
                  lg: { w: 4, h: 6, x: 0, y: 0 }
                  md: { w: 6, h: 6, x: 0, y: 0 }
                  sm: { w: 6, h: 6, x: 0, y: 0 }
                  xs: { w: 12, h: 6, x: 0, y: 0 }
                  xxs: { w: 12, h: 6, x: 0, y: 0 }
----
+
where:
+
`id`:: A unique custom card name in upper camel case, for example `ScorecardGithubOpenPRs`.
`props.aggregationId`:: A metric ID used by the card, for example `github.openPRs`. For the list of metric IDs, see {scorecard-plugin-book-link}#available-scorecard-metric-providers-and-metric-ids_evaluate-project-health-using-scorecards[Available Scorecard metric providers and metric IDs].

. Register the aggregation card in the `homepage.defaultWidgets` section:
+
[source,yaml]
----
homepage:
  defaultWidgets:
    - id: rhdh-onboarding-section
      ref: rhdh-onboarding-section
      props:
        title: Onboarding section
    - id: rhdh-entity-section
      ref: rhdh-entity-section
      props:
        title: Entity section
    - id: rhdh-template-section
      ref: rhdh-template-section
      props:
        title: Template section
    - id: scorecard-aggregated-card
      ref: scorecard-aggregated-card
----

. Save the modified configuration file and restart your {product} instance.

.Verification
. Access your {product-short} homepage interface.
. Verify that the Scorecard aggregation card displays data for the configured metric ID.
