= Configure on a customizable home page

[role="_abstract"]
You can add the aggregated Scorecard widget to a customizable {product-very-short} home page to monitor the collective technical health of your portfolio.

.Prerequisites

* You established owner group relationships in the Software Catalog.
* {scorecard-plugin-book-link}#assembly-configuring-scorecards-in-rhdh[You have configured a Scorecard metric provider] and the integration it requires (for example, GitHub or Jira).
* You have the `scorecard.metric.read` permission.
* You have {configuring-book-link}[added a custom {product-short} application configuration].

.Procedure

. Enable the Scorecard front-end, backend, and a metric provider module in your `dynamic-plugins.yaml` file. Ensure that the file includes `dynamic-plugins.default.yaml`. The following example uses the GitHub provider; use the module for your configured provider if it is different:
+
[source,yaml]
----
includes:
  - dynamic-plugins.default.yaml

plugins:
  - package: ref://red-hat-developer-hub-backstage-plugin-scorecard
    enabled: true
  - package: ref://red-hat-developer-hub-backstage-plugin-scorecard-backend
    enabled: true
  - package: ref://red-hat-developer-hub-backstage-plugin-scorecard-backend-module-github
    enabled: true
----
+
The Homepage plugin is preinstalled and enabled by default. For more information, see {customizing-book-link}[{customizing-book-title}].

. Log in to the {product-very-short} application.
. Enter the *Edit* mode on the home page.
. Click *Add widget*, select the *Scorecard* widget, and enter an aggregation ID (for example, `github.openPRs` or a KPI key from your `scorecard.aggregationKPIs` configuration).
+
[NOTE]
====
You can add only one metric at a time. Repeat this step to add additional Scorecard widgets.
====
. Drag the widget to your preferred layout position.
. Click *Save*.

.Verification

. Log in to {product-very-short}.
. On the *Home* page, verify that the aggregated Scorecard widgets are displayed.
. Confirm that the displayed key performance indicators (KPIs) reflect the status of your owned components, systems, and resources.
