= Configure on a customizable home page

[role="_abstract"]
You can add the aggregated Scorecard card widget to a customizable {product-very-short} home page to monitor the collective technical health of your portfolio.

.Prerequisites

* You established owner group relationships in the Software Catalog.
* {scorecard-plugin-book-link}#assembly-configuring-scorecards-in-rhdh[You have installed the Scorecard plugin].
* You have the `scorecard.metric.read` permission.
* You have {configuring-book-link}[added a custom {product-short} application configuration].

.Procedure

. Open your {product-very-short} `{my-app-config-file}` file. For more information, see {configuring-book-link}[{configuring-book-title}].

. In the `app.extensions` section, configure the dynamic home page as customizable by setting `customizable: true`:
+
[source,yaml]
----
app:
  extensions:
    - page:home: false
    - page:homepage:
        config:
          path: /
          title: Home
    - api:home/visits: true
    - app-root-element:home/visit-listener: true
    - home-page-layout:homepage/dynamic-homepage-layout:
        config:
          customizable: true
----

. Register the aggregated Scorecard card in the `homepage.defaultWidgets` section:
+
[source,yaml]
----
homepage:
  defaultWidgets:
    - id: rhdh-onboarding-section
      ref: rhdh-onboarding-section
      props:
        title: Onboarding section
    - id: rhdh-entity-section
      ref: rhdh-entity-section
      props:
        title: Entity section
    - id: rhdh-template-section
      ref: rhdh-template-section
      props:
        title: Template section
    - id: scorecard-aggregated-card
      ref: scorecard-aggregated-card
----

. Save the modified configuration file and restart your {product} instance.
+
[NOTE]
====
On a customizable home page, the default aggregated Scorecard card first displays an error because no aggregation ID is specified. You provide the aggregation ID from the user interface in the following steps.
====

. Log in to the {product-very-short} application.
. Enter the *Edit* mode on the home page.
. On the aggregated Scorecard card, click *Edit*, and then click *Settings*.
. In the *aggregationId* field, enter a valid aggregation ID. The aggregation ID is either a metric ID, for example `github.openPRs` or `jira.openIssues`, or the key of a custom `scorecard.aggregationKPIs` entry. For the list of metric IDs, see {scorecard-plugin-book-link}#available-scorecard-metric-providers-and-metric-ids_evaluate-project-health-using-scorecards[Available Scorecard metric providers and metric IDs]. To define a custom aggregation ID, see {scorecard-plugin-book-link}#configure-aggregated-kpis-for-the-scorecard_configure-aggregated-scorecard-kpis[Configure aggregated KPIs for the Scorecard].
. Drag the card to your preferred layout position.
. Click *Save*.
+
[NOTE]
====
To add another aggregated Scorecard card widget, enter *Edit* mode again, click *Add widget*, click *Settings*, and then enter a valid aggregation ID.
====

.Verification

. Log in to {product-very-short}.
. On the *Home* page, verify that the aggregated Scorecard card widget is displayed with the name you provided.
. Confirm that the displayed key performance indicators (KPIs) reflect the status of your owned components, systems, and resources.
