= Update custom Helm chart configurations

[role="_abstract"]
In {product-very-short} 2.1, the standalone Helm chart changes the structure of the `values.yaml` file, so you must translate your existing configuration keys to the new format before you upgrade.

If you are upgrading from version 1.10 to version 2.1, migrate your values file to the new structure and then upgrade the existing release in place with `helm upgrade`; you do not need to uninstall the 1.x release. The complete key-by-key `values.yaml` mapping, including keys that are removed or restructured and the required plugin reference changes, is covered in link:{migrating-book-link}[{migrating-book-title}]. Follow the link:{migrating-book-link}#proc-migrate-helm-chart-values-to-rhdh-2-1_migrate-from-rhdh-1-10-to-2-1[Migrate Helm chart values to {product-very-short} 2.1] procedure in that guide to update your custom configurations.
