= Run the {product-very-short} Upgrade Helper skill

[role="_abstract"]
Run the {product-very-short} Upgrade Helper skill to produce a prioritised report of predicted upgrade issues for your {product} instance.

.Prerequisites

* You have link:https://docs.anthropic.com/en/docs/claude-code/getting-started[Claude Code] installed and authenticated.
* You have cloned or installed the link:https://github.com/redhat-developer/rhdh-users-skill-pack[`rhdh-users-skill-pack`] repository, or you have added the skill pack to your Claude Code configuration.
* You have access to your current {product-very-short} configuration files:
** `app-config.yaml` — the {product} application runtime configuration file.
** Your dynamic plugins configuration YAML — the file that controls plugin enablement, versions, and overrides.
* Optional: You have a file containing your runtime environment variable values (for example, a `.env` file) that affect {product-very-short} behaviour.

[IMPORTANT]
====
Do not include API keys, passwords, tokens, or other credentials in any files you provide to the skill. The skill checks for secrets and warns you if it detects content that appears to contain sensitive values, but you must ensure secret values are removed or replaced with placeholders before proceeding.
====

.Procedure

. Open a terminal and change to the directory that contains your {product-very-short} configuration files.

. Run the skill by starting Claude Code with the `rhdh-users-skill-pack` active and invoking the upgrade helper skill:
+
[source,terminal]
----
$ claude --skill rhdh-upgrade-helper \
  --from <current_version> \
  --to <target_version> \
  --config app-config.yaml \
  --plugins dynamic-plugins.yaml
----
+
Replace `<current_version>` with your installed {product-very-short} version (for example, `1.8`) and `<target_version>` with the version you are upgrading to (for example, `1.10`).

. Optional: Provide your environment variable file to include runtime configuration in the analysis:
+
[source,terminal]
----
$ claude --skill rhdh-upgrade-helper \
  --from <current_version> \
  --to <target_version> \
  --config app-config.yaml \
  --plugins dynamic-plugins.yaml \
  --env .env
----

. Optional: If you have additional configuration files relevant to your deployment, provide them using repeated `--config` flags:
+
[source,terminal]
----
$ claude --skill rhdh-upgrade-helper \
  --from 1.5 \
  --to 1.9 \
  --config app-config.yaml \
  --config app-config.production.yaml \
  --plugins dynamic-plugins.yaml
----

. Review the predicted-issues report that the skill writes to your terminal. The report lists each issue in priority order. Address the issues listed before starting the upgrade.

.Verification

. The skill produces a prioritised report in your terminal that lists predicted breaking changes, configuration drift, and plugin compatibility issues for your specified upgrade path.
. If the skill detects that you are not using {product-local} ({product-local-very-short}), it recommends using it to validate your configuration against the target version in a cluster-free environment before upgrading production.
