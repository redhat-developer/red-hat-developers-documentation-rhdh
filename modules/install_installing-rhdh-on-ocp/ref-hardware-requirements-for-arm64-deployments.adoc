= Hardware requirements for ARM64 deployments

[role="_abstract"]
To size an ARM64 evaluation environment for {product}, apply the standard compute and storage guidelines and provision a multi-architecture database image.

include::{docdir}/artifacts/snip-developer-preview.adoc[]

During the {developer-preview}, ARM64 deployments of {product} use the same compute and storage guidelines as `x86_64` deployments. {company-name} plans detailed ARM64-specific CPU and memory baselines for a later release. To plan resources, see {about-book-link}#sizing-requirements-for-rhdh_about-rhdh[Compute and storage resource guidelines].

The following table lists the platform requirements that are specific to ARM64 evaluation deployments.

[cols="30%,70%", frame="all", options="header"]
|===
|Requirement
|Guideline

|CPU architecture
|64-bit Arm (`aarch64`) worker nodes on {ocp-brand-name} or a supported Kubernetes cluster.

|Container images
|Community images at `quay.io/rhdh-community`. Productized multi-architecture images are not available during the {developer-preview}.

|Database image
|A multi-architecture PostgreSQL image, such as `registry.redhat.io/rhel10/postgresql-18`, which matches the Helm chart default image family. The default embedded PostgreSQL image supports `x86_64` only and does not run on ARM64.
|===
