= ARM64 architecture support for {product}

[role="_abstract"]
To evaluate {product} on 64-bit Arm (`aarch64`) infrastructure, deploy it as a {developer-preview} on ARM64 clusters by using community container images.

include::{docdir}/artifacts/snip-developer-preview.adoc[]

During the {developer-preview}, you can run {product} ({product-very-short}) on ARM64 clusters by using the community container images at `quay.io/rhdh-community`. Productized multi-architecture images are not available during the {developer-preview}.

You can deploy {product-very-short} on ARM64 by using either of the following validated methods:

* The {product} Helm chart on an ARM64 Kubernetes cluster, such as {ocp-brand-name} on 64-bit Arm or a cloud provider that uses 64-bit Arm compute nodes.
* The {product} Operator on an ARM64 {ocp-short} cluster.

{developer-preview} validation confirms that pods reach the `Ready` state and that the {product-very-short} portal loads and supports basic navigation. {company-name} plans full functional testing, such as catalog browsing, template scaffolding, and plugin interactions, for a later release.

The default embedded PostgreSQL image that {product-very-short} deploys supports `x86_64` only and fails to start on ARM64. When you deploy on an ARM64 cluster, you must replace the default database image with a multi-architecture image.
