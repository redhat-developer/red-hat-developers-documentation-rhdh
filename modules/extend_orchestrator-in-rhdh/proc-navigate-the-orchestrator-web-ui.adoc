= Navigate the Orchestrator web UI

[role="_abstract"]
To locate workflows, review run history, and start execution runs, open Orchestrator from the *Administration* section of the {product-short} navigation. Use the *Workflows* list and the workflow pages to monitor execution metrics and access workflow details.

.Prerequisites

* You have access to an {ocp-short} deployment where the Orchestrator plugin is enabled.
* Your account has role-based permissions to view and run target workflows.

.Procedure

. In the {product-short} navigation, expand *Administration* and select *Orchestrator*.
+
Orchestrator is located in the *Administration* section. In earlier releases, it appeared in the main navigation sidebar.
. On the *Workflows* page, review the list of available workflows. The list includes reordered columns, such as the workflow name, *Runs (last month)*, and *Success ratio*:
+
.. Review the *Runs (last month)* column to see how many times each workflow ran in the last month.
.. Review the *Success ratio* column to see the ratio of successful runs to total runs for each workflow.
+
If no workflows are available, the page displays an empty-state message instead of the list.
. Select a workflow to open its page.
+
To start a run, select *Run*. If the workflow is unavailable, the *Run* button is disabled; hover over the *Run* button to display a tooltip that explains why you cannot run the workflow.
. Select a run to open the workflow run details page.
+
If the workflow has no runs, the runs list displays an empty-state message.
+
[NOTE]
====
The information shown in the Orchestrator UI is subject to your permissions. You can view only the workflows and runs that you are authorized to access.
====

.Verification

. Verify that the workflow run details page opens and displays execution status.
. Use the breadcrumbs at the top of the workflow run details page to verify that you can navigate back to the workflow or the workflows list.
