= Global and chart configuration values

[role="_abstract"]
You can customize settings that affect all chart resources, including image registries, storage classes, and resource naming.

Not all of these values are under the `global` key. The `global.*` values apply across every chart dependency, such as the built-in PostgreSQL chart dependency. The remaining values also apply chart-wide, but you set them at the top level of the chart's values file.

[cols="1m, 1, 1, 1m"]
|===
d|*Key* |*Description* |*Type* d|*Default*

|global.imageRegistry
|Global container image registry. Overrides per-image registries for all containers.
|string
|""

|global.imagePullSecrets
|Global container image registry secret names.
|list
|[]

|global.defaultStorageClass
|Global default StorageClass for PVCs.
|string
|""

|nameOverride
|Override the chart name used in resource naming.
|string
|"developer-hub"

|fullnameOverride
|Override the full resource name.
|string
|""

|commonLabels
|Labels applied to all chart resources.
|object
|{}

|commonAnnotations
|Annotations applied to all chart resources.
|object
|{}

|extraDeploy
a|Array of extra objects to deploy with the release, rendered through Helm's `tpl` function. Each item is a complete Kubernetes manifest; Helm template expressions are supported.
|list
|[]

|host
|Custom hostname for the {product-very-short} instance.
|string
|""
|===
