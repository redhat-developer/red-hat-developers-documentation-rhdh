= Intelligent Assistant values

[role="_abstract"]
You can configure the Intelligent Assistant (powered by {ls-brand-name}), the AI assistant, as a first-class feature of your {product-very-short} instance, including the dynamic plugins, configuration files, Offline Knowledge Portal (OKP), and core sidecar.

[cols="1m, 1, 1, 1m"]
|===
d|*Key* |*Description* |*Type* d|*Default*

|intelligentAssistant
|Intelligent Assistant AI configuration.
|object
e|See child keys

|intelligentAssistant.enabled
|Enable Intelligent Assistant.
|boolean
|true

|intelligentAssistant.plugins
|Dynamic plugin definitions for Intelligent Assistant. Default includes the front-end and back-end plugins.
|list
e|See description

|intelligentAssistant.config
|Configuration files for Intelligent Assistant.
|object
e|See child keys

|intelligentAssistant.config.stack.existingConfigMap.name
|Name of an existing ConfigMap containing the Lightspeed stack configuration (lightspeed-stack.yaml).
|string
|""

|intelligentAssistant.config.stack.existingConfigMap.key
|Key within the ConfigMap that holds the file content. Defaults to the bundled filename (lightspeed-stack.yaml) if not set.
|string
|""

|intelligentAssistant.config.profile.existingConfigMap.name
|Name of an existing ConfigMap containing the Python profile with prompt templates (rhdh-profile.py).
|string
|""

|intelligentAssistant.config.profile.existingConfigMap.key
|Key within the ConfigMap that holds the file content. Defaults to the bundled filename (rhdh-profile.py) if not set.
|string
|""

|intelligentAssistant.existingSecret
a|Name of an existing Secret that supplies credentials and settings to the lightspeed-core container. Configure the provider itself in lightspeed-stack.yaml. If empty, no Secret is loaded.

Expected keys (all optional; include only keys used by the configured provider): `VLLM_URL`, `VLLM_API_KEY`, `VLLM_MAX_TOKENS`, `VLLM_TLS_VERIFY`, `OPENAI_API_KEY`, `VERTEX_AI_PROJECT`, `VERTEX_AI_LOCATION`, `GOOGLE_APPLICATION_CREDENTIALS`, `ENABLE_VALIDATION`, `VALIDATION_PROVIDER`, `VALIDATION_MODEL_NAME`.

Set `ENABLE_VALIDATION` to `question_validity` to enable validation. `GOOGLE_APPLICATION_CREDENTIALS` must be a path to a credentials file mounted in the sidecar.
|string
|""

|intelligentAssistant.runtimeVolume
|Writable scratch volume for the sidecar (/tmp).
|object
e|See child keys

|intelligentAssistant.runtimeVolume.type
a|Volume type: `emptyDir` or `persistentVolumeClaim`.
|string
|"emptyDir"

|intelligentAssistant.runtimeVolume.emptyDir
|Raw Kubernetes emptyDir volume spec. Used when type is `emptyDir`.
|object
|{}

|intelligentAssistant.runtimeVolume.persistentVolumeClaim
|Raw Kubernetes PVC volume spec. Used when type is `persistentVolumeClaim`.
|object
|{}
