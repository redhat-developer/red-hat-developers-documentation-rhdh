= Data mapping specifications

[role="_abstract"]
Review the key data that the connector automatically propagates from KServe and the Kubeflow Model Catalog.

* KServe `InferenceService` resources (generated `AiModelServerAPI` entities):
** URL of the model server endpoint (`spec.serverUrl`), discovered from the {ocp-short} `Route` or the Kubernetes `Service`.
** Model serving protocol or platform type (`spec.serverType`).
** Authentication requirement status (`spec.requiresApiKey`).
** The models served by the model server (`spec.models`).
* Kubeflow Model Catalog:
** Model card content, imported as {product-very-short} TechDocs.

The connector also applies the entity owner, lifecycle, and system values that you set through `rhdh.io/` annotations on the `InferenceService` or through the connector default configuration. For more information, see xref:inferenceservice-annotations_{context}[KServe InferenceService annotations reference].
