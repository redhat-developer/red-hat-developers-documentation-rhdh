= Install the AiResource catalog backend plugin

[role="_abstract"]
To catalog AI content assets as `AiResource` entities, add the `AiResource` catalog backend module to your dynamic plugins configuration. No additional `app-config` configuration is required.

.Prerequisites

* Your {product-very-short} instance is installed and running.

.Procedure

. In your dynamic plugins configuration (for example, `dynamic-plugins.yaml`), add the `AiResource` catalog backend module:
+
[source,yaml]
----
includes:
  - dynamic-plugins.default.yaml
plugins:
  - package: oci://ghcr.io/redhat-developer/rhdh-plugin-export-overlays/red-hat-developer-hub-backstage-plugin-catalog-backend-module-ai-resource-extensions:<tag>
    disabled: false
----
+
include::{docdir}/artifacts/snip-tag-for-OCI-package-paths.adoc[]
. The `skill` and `rule` kinds also require the upstream {backstage} `catalog-backend-module-ai-model` module. If this module is not already included in your image, add it to your dynamic plugins configuration.

.Verification

. Confirm the plugin is active by checking the {product-very-short} logs for "loaded" status messages.
. In the Software Catalog, the *Kind* drop-down list includes *AiResource*.
