= Register AiResource entities with {ls-short} and MCP

[role="_abstract"]
If {ls-short} and the Model Context Protocol (MCP) actions for {product-very-short} are available, you can ask {ls-short} to register an `AiResource` entity in the catalog. {ls-short} uses the MCP catalog register action to add the entity.

.Prerequisites

* {ls-brand-name} is enabled and configured in your {product-very-short} instance.
* The Model Context Protocol catalog tools are enabled.
* You have a `catalog-info.yaml` file with `kind: AiResource` that is accessible by URL.

.Procedure

. In {ls-short}, ask the assistant to register the asset and provide the URL of the `catalog-info.yaml` file. For example: `Register the AI content asset at _<url>_`.
. Confirm the action when {ls-short} prompts you.

.Verification

* The `AiResource` entity appears in the Software Catalog and in the search results.
