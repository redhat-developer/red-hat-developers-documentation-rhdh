= Register a source repository AI content asset

[role="_abstract"]
Register an AI content asset that is stored in a Git source repository by adding a `catalog-info.yaml` file with `kind: AiResource` and registering it through the standard catalog self-service flow or a catalog location.

.Prerequisites

* You have installed and configured the {product} instance.
* You have enabled the `AiResource` catalog backend plugin. See xref:installing-the-airesource-plugin_{context}[Install the AiResource catalog backend plugin].
* You have a Git repository that contains AI content, such as skills or rules.
* If RBAC is enabled, you have a role with the following permissions: `catalog.entity.create`, `catalog.location.create`.

.Procedure

. In the root directory of the repository that contains your AI content, create a file named `catalog-info.yaml`:
+
[source,yaml]
----
apiVersion: backstage.io/v1alpha1
kind: AiResource
metadata:
  name: _<your_ai_content_asset>_
  description: _<asset_brief_description>_
  tags:
    - ai-rules
  annotations:
    backstage.io/source-location: url:_<repository_url>_
spec:
  type: skill
  lifecycle: experimental
  owner: _<your_team_name>_
----
+
Set `spec.type` to `skill` or `rule` to match the content of the asset.
. Commit the `catalog-info.yaml` file to the root of your repository.
. Register the entity by using one of the following methods:
+
--
* In your {product} navigation menu, go to *Catalog* > *Self-service*, click *Register Existing Component*, enter the full URL of the `catalog-info.yaml` file in your repository, and complete the wizard instructions.
* Add the location to your `app-config` file:
+
[source,yaml]
----
catalog:
  locations:
    - type: url
      target: _<repository_url>_/blob/main/catalog-info.yaml
----
--

.Verification

. The asset is listed in the Software Catalog when you filter by *Kind* = *AiResource*.
. On the entity detail page, the asset location is shown as a clickable link to the source repository.
