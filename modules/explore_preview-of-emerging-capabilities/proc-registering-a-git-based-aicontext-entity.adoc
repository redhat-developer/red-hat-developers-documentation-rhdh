= Register a source repository AI content asset

[role="_abstract"]
Register an AI content asset that is stored in a Git source repository by adding a `catalog-info.yaml` file with `kind: AIContext` and registering it through the standard catalog self-service flow.

.Prerequisites

* You have installed and configured the {product} instance.
* You have a Git repository that contains AI content, such as skills, rules, or agent definitions.
* If RBAC is enabled, you have a role with the following permissions: `catalog.entity.create`, `catalog.location.create`.

.Procedure

. In the root directory of the repository that contains your AI content, create a file named `catalog-info.yaml`:
+
[source,yaml]
----
apiVersion: backstage.io/v1alpha1
kind: AIContext
metadata:
  name: _<your_ai_content_asset>_
  description: _<asset_brief_description>_
  tags:
    - ai-rules
  annotations:
    backstage.io/techdocs-ref: dir:.
spec:
  type: mixed
  scope: team
  owner: _<your_team_name>_
  lifecycle: experimental
  location:
    type: git
    target: _<repository_url>_
----
. Commit the `catalog-info.yaml` file to the root of your repository.
. In your {product} navigation menu, go to *Catalog* > *Self-service*.
. On the *Self-service* page, click *Register Existing Component*.
. On the *Register an existing component* page, enter the full URL of the `catalog-info.yaml` file in your repository.
. Complete the wizard instructions.

.Verification

. The asset is listed in the Software Catalog when you filter by *Kind* = *AIContext*.
. On the entity detail page, the asset location is shown as a clickable link to the source repository.
