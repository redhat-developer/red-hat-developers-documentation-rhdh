= Troubleshoot AIContext schema validation errors

[role="_abstract"]
When {product-very-short} ingests an `AIContext` entity, the catalog processor validates the entity against the schema. If a required field is missing or a field value is invalid, ingestion fails and the catalog reports an actionable error that identifies the field to correct.

A valid entity that contains all required fields is accepted and indexed without errors. The following table lists common validation problems and how to resolve them.

[cols="1,1,1", options="header"]
|===
| Symptom | Cause | Resolution

| Ingestion fails with an error that names a missing field, such as `spec.location`.
| A required field is missing from the `catalog-info.yaml` file.
| Add the missing field, and then register the entity again.

| Ingestion fails with an error that identifies `spec.location.type`.
| The `spec.location.type` value is not one of the accepted values.
| Set `spec.location.type` to `git` or `oci`.

| Ingestion fails with an error that identifies `spec.location.target`.
| The `spec.location.target` value does not match the expected pattern for the specified `spec.location.type`.
| Provide a source repository URL for `type: git`, or an OCI image reference for `type: oci`.
|===

[NOTE]
====
The exact wording of validation messages is determined by the catalog processor. Messages are human-readable and identify the specific field so that you can correct the entity without inspecting source code.
====
