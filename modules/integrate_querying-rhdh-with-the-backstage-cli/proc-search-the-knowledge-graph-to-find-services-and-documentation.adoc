= Search the knowledge graph to find services and documentation

[role="_abstract"]
To discover relevant services, documentation, or templates across your organization, search the {product} knowledge graph by using the {backstage} CLI to query all indexed content types, including TechDocs.

.Prerequisites

* You have installed and authenticated the {backstage} CLI. For details, see xref:install-and-authenticate-the-backstage-cli-for-rhdh-access_{context}[].

.Procedure

* To search across all content types, replace `_<search_term>_` with your query:
+
[source,terminal]
----
backstage-cli search "<search_term>"
----
+
.Example
[source,terminal]
----
backstage-cli search "payment" --output=json
----

* To filter by content type, add the `--types` flag:
+
[source,terminal]
----
backstage-cli search "onboarding" --types software-catalog
----

* To limit the number of results:
+
[source,terminal]
----
backstage-cli search "payment" --page-limit 10 --output=json
----

* To search TechDocs content only, use the `docs search` command:
+
[source,terminal]
----
backstage-cli docs search "<search_term>"
----
+
.Example: searching for onboarding documentation
[source,terminal]
----
backstage-cli docs search "onboarding guide" --output=json
----
+
The `docs search` command automatically filters results to TechDocs content, unlike the general `search` command.
