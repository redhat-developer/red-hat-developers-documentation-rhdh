= Run software templates to create standardized projects

[role="_abstract"]
To create new projects or components that follow your organization's standards, discover and run a software template in {product} by using the {backstage} CLI.

.Prerequisites

* You have installed and authenticated the {backstage} CLI. For details, see xref:install-and-authenticate-the-backstage-cli-for-rhdh-access_{context}[].

.Procedure

. List the available software templates:
+
[source,terminal]
----
backstage-cli template list --output=json
----

. Validate the template with a dry run by replacing `_<template_ref>_` with the entity reference (for example, `template:default/create-nodejs-app`) and `_<values_json>_` with a JSON string of template parameter values:
+
[source,terminal]
----
backstage-cli template dry-run --template-ref <template_ref> --values '<values_json>'
----
+
A dry run validates your parameters and simulates the process without creating any resources.

. If the dry run succeeds, run the template:
+
[source,terminal]
----
backstage-cli template execute --template-ref <template_ref> --values '<values_json>'
----
+
.Example
[source,terminal]
----
backstage-cli template execute \
  --template-ref template:default/create-nodejs-app \
  --values '{"name": "my-new-service", "owner": "team-a"}' \
  --output=json
----
+
The command returns a task ID that you can use to track progress.

[IMPORTANT]
====
Template execution creates real resources such as repositories and catalog entries. Always validate with `template dry-run` first.
====
