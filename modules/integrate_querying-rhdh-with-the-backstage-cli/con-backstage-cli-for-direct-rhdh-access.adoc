= {backstage} CLI for direct {product} access

[role="_abstract"]
The {backstage} CLI provides intent-based commands that let AI coding agents and developers query the {product} software catalog, API specifications, templates, and documentation directly from the terminal.

include::{docdir}/artifacts/snip-developer-preview.adoc[]

AI coding agents and developers need organizational context to avoid duplicating existing services, bypassing governance, or ignoring standards. The {backstage} CLI connects to a running {product} ({product-very-short}) instance and provides intent-based commands that surface this context directly in your terminal or agent workflow.

You can use the CLI to:

* *Query the software catalog* to find components, APIs, systems, groups, and resources across your organization.
* *Retrieve API specifications* such as `OpenAPI`, `AsyncAPI`, or `GraphQL` definitions to understand service interfaces.
* *Search the knowledge graph* to discover relevant entities, documentation, and templates.
* *List and run software templates* to create new projects that follow your organization's standards.

The CLI provides two output modes:

* *Human-readable* (default) for interactive terminal use.
* *JSON* (`--output=json`) for programmatic consumption by AI coding agents and automation scripts.

Every command supports `--help`, which exposes the full command surface so that an AI agent can discover and operate the CLI without prior knowledge of internal action names.
