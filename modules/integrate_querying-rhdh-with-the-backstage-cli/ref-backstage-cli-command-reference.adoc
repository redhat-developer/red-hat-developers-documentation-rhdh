= {backstage} CLI command reference

[role="_abstract"]
The {backstage} CLI command reference lists all available commands for querying {product} resources, including the flags, options, and output formats that each command supports.

== Global flags

The following flags apply to all commands:

[cols="1,3", options="header"]
|===
| Flag | Description

| `--output <format>`
| Output format: `human` (default) or `json`.

| `--instance <name>`
| Target a specific authenticated {product-very-short} instance.

| `--no-color`
| Suppress color codes in output.

| `--help`
| Show help with all available flags and subcommands.
|===

== Authentication commands

[cols="1,3", options="header"]
|===
| Command | Description

| `auth login --backend-url <url>`
| Authenticate with a {product-very-short} instance using OAuth2 with Proof Key for Code Exchange (PKCE).

| `auth logout`
| Log out and clear stored credentials.

| `auth list`
| List all authenticated instances.

| `auth show`
| Show details of the currently selected instance.

| `auth select`
| Select the default instance.

| `auth print-token`
| Print an access token to stdout.
|===

== Catalog commands

[cols="1,3", options="header"]
|===
| Command | Description

| `catalog list`
| List catalog entities. Flags: `--kind`, `--type`, `--filter <json>`, `--limit <n>`, `--fields <json>`.

| `catalog get`
| Get a specific entity. Flags: `--name` (required), `--kind`, `--namespace`.

| `catalog validate`
| Validate entity YAML. Flags: `--entity` (required), `--location`.

| `catalog register`
| Register an entity. Flags: `--location-url` (required).

| `catalog unregister`
| Unregister an entity. Flags: `--location-id` or `--location-url` (one required).
|===

== API commands

[cols="1,3", options="header"]
|===
| Command | Description

| `api list`
| List API entities. Flags: `--type` (`openapi`, `asyncapi`, `graphql`, `gRPC`), `--limit <n>`.

| `api get-spec`
| Get the full API specification. Flags: `--name` (required), `--namespace`.
|===

== Search commands

[cols="1,3", options="header"]
|===
| Command | Description

| `search "<term>"`
| Search across all content types. Flags: `--types`, `--filters`, `--page-limit`, `--page-cursor`.
|===

== TechDocs commands

[cols="1,3", options="header"]
|===
| Command | Description

| `docs search "<term>"`
| Search TechDocs content. Flags: `--page-limit`, `--page-cursor`.
|===

== Template commands

[cols="1,3", options="header"]
|===
| Command | Description

| `template list`
| List available software templates. Flags: `--limit <n>`.

| `template execute`
| Run a software template. Flags: `--template-ref` (required), `--values` (required), `--secrets`.

| `template dry-run`
| Validate a template without creating resources. Flags: `--template-ref` (required), `--values`.
|===
