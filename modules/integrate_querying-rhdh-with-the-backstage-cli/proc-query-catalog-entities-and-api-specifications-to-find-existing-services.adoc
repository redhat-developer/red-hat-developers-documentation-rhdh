= Query catalog entities and API specifications to find existing services

[role="_abstract"]
To find existing components, APIs, systems, or teams before creating new ones, query the {product} software catalog by using the {backstage} CLI to list and retrieve entities by kind, type, or name, and retrieve full API specifications.

.Prerequisites

* You have installed and authenticated the {backstage} CLI. For details, see xref:install-and-authenticate-the-backstage-cli-for-rhdh-access_{context}[].

.Procedure

* To list all entities of a specific kind, replace `_<entity_kind>_` with `Component`, `API`, `System`, `Group`, `User`, `Resource`, or `Domain`:
+
[source,terminal]
----
backstage-cli catalog list --kind <entity_kind>
----
+
.Example: listing all components as JSON
[source,terminal]
----
backstage-cli catalog list --kind Component --output=json
----

* To narrow results by entity type, add the `--type` flag:
+
[source,terminal]
----
backstage-cli catalog list --kind Component --type service
----

* To retrieve a single entity by name, add `--namespace _<ns>_` if the entity is not in the `default` namespace:
+
[source,terminal]
----
backstage-cli catalog get --name <entity_name> --kind <entity_kind>
----

* To register a new entity from a repository, replace `_<catalog_info_url>_` with the URL of the `catalog-info.yaml` file:
+
[source,terminal]
----
backstage-cli catalog register --location-url <catalog_info_url>
----

* To validate an entity definition before registering it:
+
[source,terminal]
----
backstage-cli catalog validate --entity "$(cat entity.yaml)"
----

* To remove an entity registration:
+
[source,terminal]
----
backstage-cli catalog unregister --location-url <catalog_info_url>
----

* To list API entities and filter by type:
+
[source,terminal]
----
backstage-cli api list --type openapi --output=json
----

* To retrieve the full specification for an API entity, replace `_<api_name>_` with the name of the API entity:
+
[source,terminal]
----
backstage-cli api get-spec --name <api_name>
----
+
.Example: retrieving an `OpenAPI` specification
[source,terminal]
----
backstage-cli api get-spec --name payments-api --output=json
----
+
In human-readable mode, the command prints the raw specification content. In JSON mode, the output includes the API name, type, and full specification definition.
