= Install and authenticate the {backstage} CLI for {product} access

[role="_abstract"]
To start querying your {product} instance from the command line, install the {backstage} CLI and authenticate it with OAuth2 so that subsequent commands can access your catalog, APIs, and templates.

.Prerequisites

* You have a running {product-very-short} instance (version {product-version} or later).
* You have Node.js v22 or later and `npm` installed.
* A {product-very-short} administrator has enabled the auth plugin and OAuth2 endpoints. For details, see xref:enable-the-auth-plugin-for-cli-access_{context}[].

.Procedure

. Install the {backstage} CLI globally:
+
// TODO: Verify whether standalone execution (RHIDP-14128) has landed.
// If standalone mode is available, use: npm install -g @backstage/cli
// If not, document the NPM_CONFIG_LEGACY_PEER_DEPS workaround.
+
[source,terminal]
----
NPM_CONFIG_LEGACY_PEER_DEPS=true npm install -g @backstage/cli
----

. Log in to your {product-very-short} instance by replacing `_<rhdh_url>_` with the URL of your {product-very-short} instance, for example, `\https://my-rhdh.example.com`:
+
[source,terminal]
----
backstage-cli auth login --backend-url <rhdh_url>
----
+
A browser window opens for OAuth2 authentication. After you approve the request, the CLI stores your credentials locally.

. Verify your authentication:
+
[source,terminal]
----
backstage-cli auth list
----

.Verification

Run a test query to confirm the CLI can reach your {product-very-short} instance:

[source,terminal]
----
backstage-cli catalog list --kind Component --output=json
----

If the command returns a JSON array of Component entities, the CLI is ready. If you receive an authentication error, repeat the login step.
