= Chart-managed system resources

[role="_abstract"]
The {product} 2.1 standalone Helm chart manages system resources automatically. You can remove these resources from +extra*+ fields in your migrated values file.

== Volumes

The following volumes are now managed by the chart. Remove them from +extraVolumes+ if present:

* +dynamic-plugins-root+
* +dynamic-plugins+
* +dynamic-plugins-npmrc+
* +dynamic-plugins-registry-auth+
* +npmcacache+
* +extensions-catalog+
* +temp+

== Volume mounts

The following volume mounts are now managed by the chart. Remove them from +extraVolumeMounts+ if present:

* +/opt/app-root/src/dynamic-plugins-root+
* +/dynamic-plugins-root+
* +/opt/app-root/src/dynamic-plugins.yaml+
* +/extensions+
* +/tmp+

== Environment variables

The following environment variables are now managed by the chart. Remove them from +extraEnvVars+ if present:

* +APP_CONFIG_backend_listen_port+
* +NPM_CONFIG_USERCONFIG+
* +POSTGRES_HOST+ (auto-injected when using internal PostgreSQL)
* +POSTGRES_PORT+ (auto-injected when using internal PostgreSQL)
* +POSTGRES_USER+ (auto-injected when using internal PostgreSQL)
* +POSTGRES_PASSWORD+ (auto-injected when using internal PostgreSQL)

== Init containers

The following init containers are now managed by the chart. Remove them from custom configurations if present:

* +install-dynamic-plugins+

[NOTE]
====
Custom resources not listed here should remain in your +extra*+ fields during migration.
====
