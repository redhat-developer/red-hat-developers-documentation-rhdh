= Prepare custom plugins for the New Frontend System

[role="_abstract"]
Custom plugins built on the Old Frontend System (OFS) need New Frontend System (NFS) support added before the platform upgrade, so that you can deploy them on 2.1 without rework. Instead of rewriting plugins, you add the NFS entry point and extensions alongside your existing code.

This phase helps you understand the NFS changes, update your custom plugins to support the NFS, and test the updated plugins before the platform upgrade.
