= Prepare custom plugins for the New Frontend System

[role="_abstract"]
Custom plugins built on the old frontend system need New Frontend System support added before the platform upgrade, so you can deploy them on 2.1 without rework. You do not rewrite the plugins; you add the New Frontend System entry point and extensions alongside your existing code.

This phase helps you understand the New Frontend System changes, update your custom plugins to support the New Frontend System, and test the updated plugins before the platform upgrade.
