= Plugin distribution changes in {product-very-short} 2.1

[role="_abstract"]
{product} 2.1 discontinues Janus IDP wrapper packages and distributes plugins exclusively as OCI artifacts. GA-supported plugins use the OCI path format, while preview-status plugins must have all wrappers updated.
