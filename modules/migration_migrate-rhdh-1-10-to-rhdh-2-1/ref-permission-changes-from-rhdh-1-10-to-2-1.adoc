= Permission changes from {product-very-short} 1.10 to 2.1

[role="_abstract"]
When migrating from {product-very-short} 1.10 to 2.1, use the following tables and policy examples to find the new, changed, and removed role-based access control (RBAC) permissions and update your policies.

== New, changed, and removed permissions

The permission model changes affect the {ia-short} features. The following table groups the changes by feature.

[options="header"]
|===
| Feature | Status | 1.x permissions | 2.1 permission

| Chat
| Changed
| `lightspeed.chat.read`, `lightspeed.chat.create`, `lightspeed.chat.update`, `lightspeed.chat.delete`
| `intelligent-assistant.chat`

| Notebooks
| Changed
| `lightspeed.notebooks.use`
| `intelligent-assistant.notebooks`

| MCP tools
| Changed
| `lightspeed.mcp.read`, `lightspeed.mcp.manage`
| `intelligent-assistant.mcp.tools`

| Agent Skills
| New
| _(none)_
| `intelligent-assistant.skills`

| CRUD action verbs
| Removed
| `read`, `create`, `update`, `delete` actions on `lightspeed.{asterisk}` permissions
| Replaced by the single `use` action
|===

For the per-permission mapping and example policy lines, see xref:ref-ai-permissions-mapping-1-x-to-2-1_{context}[AI permissions mapping from 1.x to 2.1].

== Before and after policy CSV example

The following example shows a 1.x policy CSV file that grants a team access to the chat, Notebooks, and MCP features by using the old CRUD permissions:

[source,text,subs="+quotes"]
----
p, role:default/_<team>_, lightspeed.chat.read, read, allow
p, role:default/_<team>_, lightspeed.chat.create, create, allow
p, role:default/_<team>_, lightspeed.chat.update, update, allow
p, role:default/_<team>_, lightspeed.chat.delete, delete, allow
p, role:default/_<team>_, lightspeed.notebooks.use, use, allow
p, role:default/_<team>_, lightspeed.mcp.read, read, allow
p, role:default/_<team>_, lightspeed.mcp.manage, update, allow
----

The following example shows the equivalent {product-version} policy CSV file. Each feature uses a single permission and the `use` action, so the four chat lines and the two MCP lines each collapse to one line:

[source,text,subs="+quotes"]
----
p, role:default/_<team>_, intelligent-assistant.chat, use, allow
p, role:default/_<team>_, intelligent-assistant.notebooks, use, allow
p, role:default/_<team>_, intelligent-assistant.mcp.tools, use, allow
----

[IMPORTANT]
====
This is a breaking change. {product-very-short} {product-version} does not recognize the old `lightspeed.{asterisk}` identifiers or the old CRUD action verbs, and ignores them without an error. Update every policy CSV file, conditional policy rule, and automation script before you upgrade.
====
