= Helm chart changes in {product-very-short} 2.1

[role="_abstract"]
The {product} 2.1 Helm chart is a standalone chart that replaces the 1.x chart structure. Running `helm upgrade` from 1.x is not supported—you must uninstall the 1.x release and perform a fresh install.
