= Helm chart changes in {product-very-short} 2.1

[role="_abstract"]
The {product} 2.1 Helm chart is a standalone chart that replaces the 1.x chart structure. After you migrate your values file to the new structure, you can upgrade the existing release in place; you do not need to uninstall it first.

The `values.yaml` keys move from the `upstream.backstage` and `global` paths to root-level keys. Because of this change, you must update your 1.x values file before you can use it with the 2.1 chart. If you use the bundled PostgreSQL subchart with a local database, also account for the new PostgreSQL 18 default image before you upgrade.
