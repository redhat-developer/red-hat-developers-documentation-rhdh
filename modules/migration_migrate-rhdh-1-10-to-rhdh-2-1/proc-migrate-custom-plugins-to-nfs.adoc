= Migrate custom plugins to the New Frontend System

[role="_abstract"]
Custom plugins built with Old Frontend System (OFS) APIs must be rewritten to use New Frontend System (NFS) extensions and re-exported as dynamic plugins before you can deploy them on {product} 2.1.

.Prerequisites

* You have access to the source code of your custom plugins.
* You have {product} Local or a separate {product} instance for testing migrated plugins.

.Procedure

. Rewrite OFS plugin registration to NFS extensions.
.. Replace `dynamicRoutes`, `mountPoints`, `routeBindings`, `appIcons`, and `apiFactories` with their NFS equivalents.
.. Refer to the xref:ref-ofs-to-nfs-config-key-mapping_{context}[OFS to NFS configuration key mapping] for the complete mapping.

. Re-export your plugin as a dynamic plugin.

. Test your migrated plugin using {product} Local or a separate {product} instance.

.Verification

* Confirm that the plugin loads without errors and all functionality works as expected.
