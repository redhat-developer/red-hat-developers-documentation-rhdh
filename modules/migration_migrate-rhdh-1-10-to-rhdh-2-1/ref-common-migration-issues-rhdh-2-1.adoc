= Common migration issues for {product-very-short} 2.1

[role="_abstract"]
After completing all migration steps, some issues—such as silently ignored permissions or missing plugin registrations—may not produce error messages and require targeted verification.

[options="header"]
|===
| Symptom | Cause | Solution

| Custom plugins do not load
| Plugin still uses OFS APIs
| Migrate the plugin to NFS extensions using the xref:proc-migrate-custom-plugins-to-nfs_phase-2-prepare-custom-plugins[custom plugin migration procedure]

| RBAC policies do not work
| Old `lightspeed.{asterisk}` permission names are silently ignored
| Update RBAC policies using the xref:ref-ai-permissions-mapping-1-x-to-2-1_phase-4-update-configuration[AI permissions mapping]

| AI assistant features are unavailable
| Configuration keys still use `lightspeed` instead of `intelligent-assistant`
| Rename configuration keys using the xref:proc-migrate-ai-assistant-configuration_phase-4-update-configuration[AI assistant migration procedure]

| Plugins fail to install
| Using old npm package references instead of OCI artifacts
| Replace npm references with OCI artifact URLs using the xref:ref-janus-idp-to-rhdh-2-1-plugin-mapping_phase-4-update-configuration[plugin mapping reference]

| Container images fail to pull in disconnected environments
| Using old RHEL 9 image names
| Update image references using the xref:ref-container-image-renames-rhel-9-to-rhel-10_phase-3-reinstall-platform[container image renames reference]

|===
