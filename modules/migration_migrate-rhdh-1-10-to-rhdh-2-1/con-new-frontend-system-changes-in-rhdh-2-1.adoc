= New Frontend System changes in {product-very-short} 2.1

[role="_abstract"]
{product} 2.1 removes the old frontend system (OFS); all plugins must use the New Frontend System (NFS). Supported plugins work with both systems. Custom OFS plugins fail to load after the upgrade until you add NFS support. Customized `dynamicPlugins.frontend` config must also move to `app.*`.
