= New Frontend System changes in {product-very-short} 2.1

[role="_abstract"]
{product} 2.1 removes the old frontend system (OFS) and requires all plugins to use the New Frontend System (NFS). Red Hat supported plugins are compatible with both systems, but custom plugins built on OFS APIs stop working silently after the upgrade.

// OFS removal, NFS as sole architecture, impact on custom plugins. Red Hat supported plugins are compatible with both systems; only custom plugins require migration.
