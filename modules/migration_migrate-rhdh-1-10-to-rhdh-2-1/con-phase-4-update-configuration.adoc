= Update permissions and configuration to match renamed services

[role="_abstract"]
When the platform is running on 2.1, you want to update your RBAC policies, AI assistant configuration, and plugin distribution references to use the new names and formats, so you can restore access for your users and ensure the platform recognizes your existing settings.

This phase helps you migrate AI assistant configuration, update RBAC policies, reconfigure Llama Stack connections, and replace plugin package references with OCI artifact URLs.

[IMPORTANT]
====
Plugin distribution references are an exception to the "after the platform is running" timing. The bundled Dynamic Plugin Wrapper paths are not available in the 2.1 image, so you must replace them with OCI references before the first 2.1 startup. Apply the updated references in the values or custom resource that you use to install 2.1, not after the platform starts. For the steps, see xref:proc-migrate-plugins-to-oci-references_{context}[Migrate plugin references to OCI format].
====
