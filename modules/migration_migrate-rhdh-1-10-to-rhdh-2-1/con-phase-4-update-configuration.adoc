= Update permissions and configuration to match renamed services

[role="_abstract"]
In order to update the platform to run on 2.1, you need to update your RBAC policies, AI assistant configuration, and plugin distribution references to use the new names and formats, so that you can continue to provide access for your users and ensure the platform recognizes your existing settings.

This phase helps you migrate AI assistant configuration, update RBAC policies, reconfigure Llama Stack connections, and replace plugin package references with OCI artifact URLs.

[IMPORTANT]
====
Plugin distribution references are an exception to the "after the platform is running" timing. The bundled Dynamic Plugin Wrapper paths are not available in the 2.1 image, so you must replace them before the first 2.1 startup. Apply the updated references in the values or custom resource that you use to upgrade to 2.1, not after the platform starts.

Where possible, use a `ref://<plugin-name>` reference rather than a pinned `oci://` image. Because a `ref://` reference resolves by plugin name, the upgraded deployment automatically uses the newer plugin digest and rolls out the current plugin as part of the 2.1 upgrade, without a further manual change. For the steps, see xref:proc-migrate-plugins-to-oci-references_{context}[Migrate plugin references to OCI format].
====
