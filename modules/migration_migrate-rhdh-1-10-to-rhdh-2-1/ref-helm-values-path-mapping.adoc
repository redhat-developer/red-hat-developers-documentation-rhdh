= Helm values path mapping

[role="_abstract"]
This reference maps configuration paths from the {product-very-short} 1.y +backstage+ chart to the {product} 2.1 +redhat-developer-hub+ chart.

[cols="2,2,3", options="header"]
|===
| Old path (+backstage+ chart) | New path (+redhat-developer-hub+ chart) | Notes

| +upstream.backstage.image.*+ | +image.*+ | Flattened to root level
| +upstream.backstage.replicas+ | +replicaCount+ | Renamed
| +global.host+ | +host+ | Promoted to root level
| +global.clusterRouterBase+ | +openshift.clusterRouterBase+ | Reorganized under +openshift+ key
| +global.lightspeed.*+ | +intelligentAssistant.*+ | Rebranded
| +route.*+ | +openshift.route.*+ | Reorganized under +openshift+ key
| +global.dynamic.plugins+ | +dynamicPlugins.plugins+ | Flattened
| +global.auth.backend.existingSecret+ | +auth.backend.existingSecretRef.name+ | Now a structured object with +name+ and +key+ fields
| +upstream.backstage.extraEnvVars+ | +extraEnvVars+ | Flattened to root level
| +upstream.backstage.extraVolumes+ | +extraVolumes+ | Flattened to root level
| +upstream.backstage.extraVolumeMounts+ | +extraVolumeMounts+ | Flattened to root level
| +upstream.ingress.*+ | +ingress.*+ | Flattened to root level
| +upstream.service.*+ | +service.*+ | Flattened to root level
|===

[NOTE]
====
This table shows common path mappings. For a complete reference, consult the chart +values.yaml+ schema in the +redhat-developer-hub+ chart repository.
====
