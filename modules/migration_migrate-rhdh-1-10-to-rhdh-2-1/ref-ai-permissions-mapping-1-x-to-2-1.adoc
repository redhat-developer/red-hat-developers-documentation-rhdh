= AI permissions mapping from 1.x to 2.1

[role="_abstract"]
This reference lists the `intelligent-assistant.{asterisk}` permissions defined in {product-very-short} 2.1, maps them from the old `lightspeed.{asterisk}` permissions where an equivalent exists, and provides CSV policy examples.

[NOTE]
====
The {product-very-short} 2.1 intelligent assistant defines the following permissions only: `intelligent-assistant.chat`, `intelligent-assistant.notebooks`, `intelligent-assistant.mcp.tools`, and `intelligent-assistant.skills`. These are basic permissions, so the CSV policy action is `use`. There is no `intelligent-assistant.configure` permission.
====

|===
| Old permission (1.x) | New permission (2.1) | Example CSV policy

| `lightspeed.read`
| `intelligent-assistant.chat`
| `p, role:default/team_a, intelligent-assistant.chat, use, allow`

| _(none)_

| _(none)_

| _(none)_
| `intelligent-assistant.skills`
| `p, role:default/team_a, intelligent-assistant.skills, use, allow`

|===
