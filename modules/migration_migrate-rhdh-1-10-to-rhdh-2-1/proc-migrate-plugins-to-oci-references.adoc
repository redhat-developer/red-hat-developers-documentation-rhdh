= Migrate plugin references to OCI format

[role="_abstract"]
To migrate your plugin references to {product} 2.1, replace npm and wrapper package references in `dynamic-plugins.yaml` with OCI artifact URLs. This includes updating references for disconnected environment mirroring.

.Prerequisites

* You have completed the platform migration and installed the 2.1 Helm chart.
* You have access to your `dynamic-plugins.yaml` configuration file.

.Procedure

. Update plugin references in `dynamic-plugins.yaml`:
.. Replace `npm install @janus-idp/...` references with OCI artifact URLs.
.. Refer to the xref:ref-janus-idp-to-rhdh-2-1-plugin-mapping_{context}[Janus IDP to RHDH 2.1 plugin mapping] for the complete mapping.

. For disconnected environments:
.. Update your mirroring scripts to reference the new OCI artifact URLs.
.. Mirror the OCI artifacts to your internal registry.

.Verification

* Verify that all expected plugins are loaded when {product} starts.
