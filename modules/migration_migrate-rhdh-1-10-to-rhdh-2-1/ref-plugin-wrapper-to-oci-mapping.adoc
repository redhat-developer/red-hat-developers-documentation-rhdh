= Plugin wrapper to {product-very-short} 2.1 OCI reference mapping

[role="_abstract"]
In {product-very-short} 2.1, bundled Dynamic Plugin Wrapper paths and legacy community package references are no longer supported. Replace them with Open Container Initiative (OCI) references. Use this table to choose the correct reference format.

[NOTE]
====
The plugin catalog and the generated plugin tables are the authoritative source for the reference of each supported plugin. Community plugin images are published to the `ghcr.io` registry; you can browse them on the link:https://github.com/orgs/redhat-developer/packages?repo_name=rhdh-plugin-export-overlays[`rhdh-plugin-export-overlays` packages] page.
====

[options="header"]
|===
| Discontinued reference (1.x) | {product-very-short} 2.1 reference format | Notes

| `./dynamic-plugins/dist/<plugin-name>` (bundled Dynamic Plugin Wrapper path)
| `ref://<plugin-name>` or `oci://<image-reference>`
| For curated community content in the Optional Extras catalog, use a `ref://<plugin-name>` reference. For a plugin that is not in the curated catalog, use an `oci://` reference, because there is no catalog entry to resolve.

| A community plugin installed from an npm package name
| `oci://ghcr.io/redhat-developer/rhdh-plugin-export-overlays/<image-name>:<tag>!<plugin-name>`
| Community plugin images are published to `ghcr.io`. Replace the reference in `dynamic-plugins.yaml`, your Helm chart values, and your Operator custom resource (CR).

|===
