= Migrate AI assistant configuration

[role="_abstract"]
To migrate your AI assistant configuration to {product} 2.1, rename configuration keys from `lightspeed` to `intelligent-assistant`, update RBAC policies to use the new behavior-linked permission names, and reconfigure Llama Stack connections to point to LCORE.

.Prerequisites

* You have completed the platform migration and installed the 2.1 Helm chart.
* You have access to your {product} configuration files and RBAC policies.

.Procedure

. Rename AI assistant configuration keys:
.. Replace all instances of `lightspeed` with `intelligent-assistant` in your configuration files.
.. Refer to the xref:ref-ai-permissions-mapping-1-x-to-2-1_{context}[AI permissions mapping] for the complete list of changes.

. Update RBAC policies:
.. Replace CRUD-style permission names (for example, `lightspeed.read`) with behavior-linked permission names (for example, `intelligent-assistant.chat`).
.. Update route path references from `/lightspeed` to `/intelligent-assistant`.

. Reconfigure Llama Stack connections:
.. Update any Llama Stack connection settings to point to LCORE instead.

.Verification

. Verify that AI assistant features respond as expected.
. Confirm that RBAC policies grant the correct access.
