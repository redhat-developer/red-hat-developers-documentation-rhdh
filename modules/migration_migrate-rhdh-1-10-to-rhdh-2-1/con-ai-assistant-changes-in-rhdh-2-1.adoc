= AI assistant changes in {product-very-short} 2.1

[role="_abstract"]
{product} {product-version} renames the AI assistant feature from Red Hat Developer Lightspeed for Red Hat Developer Hub to Red Hat Intelligent Assistant. Configuration keys, RBAC permission names, and route paths all change. Llama Stack integration is removed and replaced by LCORE (Lightspeed Core Service).
