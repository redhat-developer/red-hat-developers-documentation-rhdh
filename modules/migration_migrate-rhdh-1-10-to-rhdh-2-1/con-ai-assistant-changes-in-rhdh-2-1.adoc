= AI assistant changes in {product-very-short} 2.1

[role="_abstract"]
{product} 2.1 renames the AI assistant feature from Lightspeed to intelligent assistant. Configuration keys, RBAC permission names, and route paths all change. Llama Stack integration is removed and replaced by LCORE (Lightspeed Core Service).
