= Pre-upgrade checklist

[role="_abstract"]
Before migrating to {product} 2.1, audit your current deployment to identify what needs to be updated.

[options="header"]
|===
| Item | Action | Notes

| Database backup
| Create a backup of your {product} database
| Essential for rollback if migration fails

| Custom plugins inventory
| List all custom plugins using OFS APIs
| Custom plugins require migration to NFS

| Helm values export
| Export current Helm chart values using `helm get values`
| Required for translating configuration keys

| RBAC permissions audit
| Review RBAC policies for `lightspeed.{asterisk}` permissions
| Permissions will need to be renamed

| Container image list
| Identify mirrored RHEL 9 images for disconnected environments
| Image names change from RHEL 9 to RHEL 10

|===
