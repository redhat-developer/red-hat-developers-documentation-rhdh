= Legacy community plugin package to {product-very-short} 2.1 OCI plugin mapping

[role="_abstract"]
Legacy `@janus-idp/<plugin-name>` community package references are deprecated and not supported in {product-very-short} 2.1. Replace these references, and any bundled Dynamic Plugin Wrapper paths, with Open Container Initiative (OCI) artifact references. Use this table to find each OCI reference.

[NOTE]
====
The plugin catalog and the generated plugin tables are the authoritative source for the OCI artifact reference of each supported plugin. If a plugin is not listed in the following table, look up its OCI reference in the plugin catalog or in the generated plugin tables.
