= Reinstall the platform with the standalone Helm chart

[role="_abstract"]
When you are ready to move your production {product} instance to 2.1, you want to export your current configuration, uninstall the 1.x release, and install the new standalone Helm chart, so you can run the platform on the updated infrastructure with the correct container images.

This phase helps you understand the Helm chart changes, translate your configuration values, update container image references, and perform the platform reinstallation.
