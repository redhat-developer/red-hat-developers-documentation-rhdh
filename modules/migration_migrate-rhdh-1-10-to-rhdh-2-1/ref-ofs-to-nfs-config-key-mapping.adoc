= Old Frontend System to New Frontend System configuration key mapping

[role="_abstract"]
This table maps every Old Frontend System (OFS) configuration key to its New Frontend System (NFS) equivalent or indicates when a feature is removed.

[options="header"]
|===
| Old Frontend System (OFS) | New Frontend System (NFS) | Notes

| `dynamicRoutes`
| NFS route extensions
| Use route extension API

| `mountPoints`
| NFS mount point extensions
| Use mount point extension API

| `routeBindings`
| NFS route bindings
| Use route binding extension API

| `appIcons`
| NFS icon extensions
| Use icon extension API

| `apiFactories`
| NFS API factory extensions
| Use API factory extension API

|===
