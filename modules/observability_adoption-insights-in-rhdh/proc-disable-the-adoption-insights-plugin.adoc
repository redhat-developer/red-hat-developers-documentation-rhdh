= Disable the Adoption Insights plugin

[role="_abstract"]
Disable the Adoption Insights plugin by updating the dynamic plugins configuration file.

.Procedure

* In your `dynamic-plugins.yaml` file, update the `package.disabled` value of the plugin to `true`:
+
[source,yaml]
----
plugins:
  # Replace <oci_reference_for_...> with the current value from the GA plugins reference table.
  - package: <oci_reference_for_backstage_community_plugin_analytics_provider_segment>
    disabled: true
----
