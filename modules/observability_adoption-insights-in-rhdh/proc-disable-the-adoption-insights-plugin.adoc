= Disable the Adoption Insights plugin

[role="_abstract"]
Disable the Adoption Insights plugin by updating the dynamic plugins configuration file.

.Procedure

* In your `dynamic-plugins.yaml` file, set `enabled` to `false` for the plugin:
+
[source,yaml]
----
plugins:
  - package: ref://backstage-community-plugin-analytics-provider-segment
    enabled: false
----
