= Set up export of filtered catalog data

Enable exporting of filtered catalog data from the Catalog Index page. Following filters are available by default:

* kind
* type
* owner
* lifecycle
* tag
* namespace
* processing
* statu

[NOTE]
====
The exported data is available in CSV and JSON formats by default, however you can configure a custom format instead.

====


.Procedure
*   Enable the export feature in the `app-config.yaml` file:
+
[source,yaml]
----
app:
  extensions:
    - page:catalog:
        config:
          exportSettings:
            enabled: true
            # Optional: hide the built-in CSV and JSON formats, showing only your own supplied exporters
            disableBuiltinExporters: false
----

.Verification
* Click on the *Export selection* button and select the data for export and export format.
