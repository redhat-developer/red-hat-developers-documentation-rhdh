= Localize quick start

[role="_abstract"]
Enable translation key support for quick start titles, descriptions, and CTAs so that users can onboard in their preferred language.

[NOTE]
====
If a translation key is present but the corresponding localized string is missing, the system defaults to the original text defined in the quick start configuration (`title`, `description`, `text`). If no translation key is defined at all, the original text is displayed.
====

.Prerequisites
* You have enabled localization in your {product-very-short} application.

.Procedure

. For *all* quick start steps (both existing and new) in your configuration file, you must define both the original text and the new localization keys. For example, in the `quickstart` section of your custom `{my-app-config-file}` file, add the `titleKey`, `descriptionKey`, and `textKey` values, as follows:
+
.`{my-app-config-file}` fragment
[source,yaml,subs="+quotes"]
----
app:
  quickstart:
    # Existing quick start steps should also be updated with keys
    - title: 'Setup Authentication'
      titleKey: steps.setupAuth.title
      description: 'Learn the basics of navigating the {product-short} interface'
      descriptionKey: steps.setupAuth.description
      icon: 'home'
      cta:
        text: 'Get Started'
        textKey: steps.setupAuth.ctaTitle
        link: '/catalog'
# ...
----
+
where:

`title`:: (Mandatory) Fallback for the title.
`titleKey`:: Key for the translated title.
`description`:: (Mandatory) Fallback for the description.
`descriptionKey`:: Key for the translated description.
`text`:: (Mandatory) Fallback for the CTA text.
`textKey`:: Key for the translated CTA text.

. In your translation override file, map the keys from the first step to the localized strings for each supported language. The Quick Start plugin is enabled by default in {product-very-short} 2.1 and registers its translation module without `mountPoints` or `translationResources` configuration.
+
.`allTranslations.json` example
[source,json]
----
{
  "plugin.quickstart": {
    "en": {
      "steps.setupAuth.title": "Set up authentication",
      "steps.setupAuth.description": "Learn the basics of navigating the portal interface",
      "steps.setupAuth.ctaTitle": "Get Started"
    },
    "fr": {
      "steps.setupAuth.title": "Configurer l'authentification",
      "steps.setupAuth.description": "Découvrez les bases de l'interface du portail",
      "steps.setupAuth.ctaTitle": "Commencer"
    }
  }
}
----
. Register and mount the translation override file as described in xref:override-translations_enable-the-localization-framework[Override default translations with JSON maps].
