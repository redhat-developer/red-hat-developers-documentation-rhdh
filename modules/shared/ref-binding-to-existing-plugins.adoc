= Override route bindings to existing plugins

[role="_abstract"]
In {product} 2.1, installed front-end plugins resolve most route bindings through the extension tree. Use `app.routes.bindings` in your `{my-app-config-file}` file only when you need to override a default binding.

For example, to bind the Catalog's TechDocs route to the TechDocs root route, add the following configuration:

[source,yaml]
----
app:
  routes:
    bindings:
      catalog.viewTechDoc: techdocs.docRoot
----

The `dynamicPlugins.frontend` `routeBindings` configuration from the old front-end system does not apply to {product} 2.1. For other configuration changes, see {configuring-book-link}#configuration-key-mapping-from-old-to-new-front-end-system_migrate-to-the-front-end-system-to-use-blueprint-based-dynamic-routing[Configuration key mapping from old to new front-end system]. If you develop custom plugins, see {configuring-book-link}#migrate-custom-plugins-to-ensure-compatibility-after-upgrade_migrate-to-the-front-end-system-to-use-blueprint-based-dynamic-routing[Migrate custom plugins to ensure compatibility after upgrade].
