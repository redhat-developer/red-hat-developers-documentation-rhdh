= Registry mirroring advanced features

[role="_abstract"]
The plugin mirroring script includes advanced features for registry fallback and path compatibility.

== Automatic registry fallback

The script automatically falls back to `quay.io/rhdh` when plugins are not yet available in `registry.access.redhat.com/rhdh`. This is useful for:

* Unreleased plugins that are only available in development registries
* Testing with pre-release builds

You might see warning messages like:
----
[WARN] Image not found at registry.access.redhat.com, using fallback: quay.io
----

This is expected behavior and indicates the script is using the fallback registry.

== Registry path compatibility

The script automatically handles different registry path formats:

* 2-level paths: `registry.io/namespace/image` (for example, `quay.io/rhdh/plugin`)
* 3-level paths: `registry.io/org/sub/image` (for example, `ghcr.io/redhat-developer/rhdh-plugin-export-overlays/plugin`)

For {ocp} internal registries, which only support 2-level paths, the script automatically flattens 3-level paths to 2-level paths by keeping only the last two path elements.
