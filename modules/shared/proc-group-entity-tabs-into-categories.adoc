= Group entity tabs into collapsible categories

[role="_abstract"]
Organize entity page tabs into collapsible groups to improve navigation when you have many tabs enabled.
Grouping helps users find related functionality by organizing tabs into logical categories such as Overview, Development, and Operations.

.Prerequisites

* {product} {product-version} or later is installed with the new front-end system enabled.
* You have access to modify your `{my-app-config-file}` file.
* You have multiple entity tabs configured.

.Procedure

. Edit your `{my-app-config-file}` file and configure the `page:catalog/entity` extension with `config.groups`:
+
[source,yaml]
----
app:
  extensions:
    # Configure tab groups for the catalog entity page
    - page:catalog/entity:
        config:
          groups:
            - title: "Overview"
              tabs:
                - entity-content:catalog/entity/overview
                - entity-content:catalog/entity/docs

            - title: "Development"
              tabs:
                - entity-content:catalog/entity/ci
                - entity-content:catalog/entity/cd
                - entity-content:catalog/entity/dependencies

            - title: "Operations"
              tabs:
                - entity-content:catalog/entity/kubernetes
                - entity-content:catalog/entity/monitoring
                - entity-content:catalog/entity/topology
----
+
Each group requires:
+
. `title`: The group name displayed in the navigation sidebar
. `tabs`: Array of `entity-content:*` extension IDs to include in this group

. Save the `{my-app-config-file}` file.

. Restart your {product} instance to apply the tab grouping changes.

.Verification

. Navigate to a catalog entity page in your {product} instance.
. Verify that tabs appear organized into collapsible groups in the entity page sidebar.
. Click a group title to expand or collapse the tabs in that group.
. Verify that tabs appear in the order you specified within each group.

+
**Group tabs by workflow phase**
+
Organize tabs to match your development workflow:

[source,yaml]
----
app:
  extensions:
    - page:catalog/entity:
        config:
          groups:
            - title: "Plan"
              tabs:
                - entity-content:catalog/entity/overview
                - entity-content:catalog/entity/docs
                - entity-content:catalog/entity/api

            - title: "Build & Test"
              tabs:
                - entity-content:catalog/entity/ci
                - entity-content:catalog/entity/dependencies
                - entity-content:catalog/entity/techdocs

            - title: "Deploy & Monitor"
              tabs:
                - entity-content:catalog/entity/cd
                - entity-content:catalog/entity/kubernetes
                - entity-content:catalog/entity/monitoring
                - entity-content:catalog/entity/topology
----
+
**Group tabs with customized titles**
+
Combine grouping with tab renaming for clarity:

[source,yaml]
----
app:
  extensions:
    - page:catalog/entity:
        config:
          groups:
            - title: "Information"
              tabs:
                - entity-content:catalog/entity/overview
                - entity-content:catalog/entity/docs

            - title: "Pipelines"
              tabs:
                - entity-content:catalog/entity/ci
                - entity-content:catalog/entity/cd

    # Rename tabs for consistency with group titles
    - entity-content:catalog/entity/ci:
        config:
          title: "Build Pipeline"
    - entity-content:catalog/entity/cd:
        config:
          title: "Deployment Pipeline"
----
+
[NOTE]
====
**Tab grouping behavior:**

. Groups appear in the order listed in the `config.groups` array
. Tabs within groups follow the order in the `tabs` array
. Ungrouped tabs appear below all groups in the order they are defined in `app.extensions`
. Group expand/collapse state resets when navigating between entity pages
. Tabs with `filter` configuration only appear in groups when the entity matches the filter criteria
