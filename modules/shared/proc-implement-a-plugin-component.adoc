= Implement an entity card with an extension blueprint

[role="_abstract"]
To display a custom entity card in Catalog, define a React component and register it with `EntityCardBlueprint`. Add the blueprint to the generated plugin's `createFrontendPlugin` extensions so {product} 2.1 can discover it.

.Prerequisites
* You have generated an NFS front-end plugin for {product} 2.1.

The blueprint attaches the card to the Catalog entity overview by default. Use a dynamic `import()` in the loader so the card's React code is not part of the plugin's synchronous entry bundle. Do not use `createComponentExtension` or `dynamicPlugins.frontend.mountPoints` for {product} 2.1.

.Procedure
. Add the Catalog React package to the generated plugin project:
+
[source,terminal,subs="+quotes"]
----
$ *yarn add @backstage/plugin-catalog-react*
----
. Align the added dependency with the {product-very-short} 2.1 release manifest:
+
[source,terminal,subs="+quotes"]
----
$ *npx @red-hat-developer-hub/cli@2.1.0 plugin upgrade --rhdh-version 2.1.0*
----
. Create `src/components/ExampleCard/ExampleCard.tsx`:
+
[source,tsx]
----
import { InfoCard } from '@backstage/core-components';
import { useEntity } from '@backstage/plugin-catalog-react';

export const ExampleCard = () => {
  const { entity } = useEntity();
  return (
    <InfoCard title="Simple Example Info">
      <p>Entity: {entity.metadata.name}</p>
    </InfoCard>
  );
};
----
. In `src/plugin.tsx`, define the entity card blueprint alongside the generated page blueprint:
+
[source,tsx]
----
import { EntityCardBlueprint } from '@backstage/plugin-catalog-react/alpha';

const exampleCard = EntityCardBlueprint.make({
  name: 'example-card',
  params: {
    filter: { kind: 'component' },
    loader: async () => {
      const { ExampleCard } = await import('./components/ExampleCard/ExampleCard');
      return <ExampleCard />;
    },
  },
});
----
. Add `exampleCard` to the `extensions` array of the existing `createFrontendPlugin` call in `src/plugin.tsx`. Keep the generated `page` extension:
+
[source,tsx]
----
extensions: [page, exampleCard],
----


.Verification
Confirm that `package.json` points its `main` field to `src/index.ts` and that `src/index.ts` default-exports the plugin created in `src/plugin.tsx`. To test the card with a Catalog entity, load the plugin in {product-local-very-short} by following xref:verify-plugins-locally_develop-custom-dynamic-plugins-to-support-custom-workflows[Verify plugins locally].
