= Update the BYOK RAG knowledge base

[role="_abstract"]
Regenerate and redeploy the vector store when your source documents change. The FAISS database is a generated artifact, so you must rebuild it from the authoritative document set rather than editing it in place.

.Prerequisites
* You have a deployed BYOK store as described in xref:verify-byok-rag-retrieval_{context}[Verify the deployed vector store].
* You have access to the updated source documents.

.Procedure

. Regenerate the complete store from the authoritative document set.
. Record the newly generated vector-store ID.
. Build and publish a new immutable image or artifact version.
. Update the runtime `vector_db_id`, `db_path` when necessary, and image reference together.
. Roll out {ia-short} and repeat the retrieval verification.
+
[IMPORTANT]
====
Changing the embedding model requires regenerating the vector store. Do not reuse a database generated with a different model or embedding dimension.
====

.Verification
* xref:verify-byok-rag-retrieval_{context}[Verify the deployed vector store]
