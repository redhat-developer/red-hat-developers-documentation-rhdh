= Retrieval augmented generation (RAG) embeddings for grounded AI responses

[role="_abstract"]
Use retrieval-augmented generation (RAG) embeddings to ground artificial intelligence (AI) responses in {product-very-short} product documentation and provide verified citations during user interactions.

{product-very-short} {ls-short} uses the Offline Knowledge Portal (OKP) as the RAG backend for product documentation. OKP is a Red Hat curated knowledge base that contains {product-very-short} product documentation optimized for RAG operations. OKP runs as a standalone service alongside the {ls-brand-name} installation.

The {lcs-name} ({lcs-short}) queries OKP during inference to retrieve version-matched {product-very-short} documentation and attaches precise documentation references to chat responses.

OKP deployment depends on your platform:

* On {ocp-short}, both the {product} Operator and Helm chart deploy and configure OKP automatically. No additional configuration is required.
* On other Kubernetes platforms, only the Helm chart can deploy OKP, and you must opt in by setting an Ingress host. The Operator does not deploy OKP on non-{ocp-short} platforms; in that case, the assistant runs without a knowledge base, and general chat still works but product-specific responses might be less accurate.

[NOTE]
====
The Notebooks feature, which enables you to upload and query your own documents, uses a separate RAG mechanism and is not affected by the OKP integration.
====
