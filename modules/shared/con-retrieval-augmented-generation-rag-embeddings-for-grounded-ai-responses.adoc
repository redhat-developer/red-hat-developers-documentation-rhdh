= Retrieval augmented generation (RAG) embeddings for grounded AI responses

[role="_abstract"]
Use retrieval-augmented generation (RAG) embeddings to ground artificial intelligence (AI) responses in {product-very-short} product documentation and provide verified citations during user interactions.

{product-very-short} {ls-short} uses the Online Knowledge Portal (OKP) as the RAG backend for product documentation. OKP is a Red Hat curated knowledge base that contains {product-very-short} product documentation optimized for RAG operations. The OKP container is installed and configured as a sidecar automatically as part of the {ls-brand-name} installation — no additional configuration is required.

The {lcs-name} ({lcs-short}) queries OKP during inference to retrieve version-matched {product-very-short} documentation and attaches precise documentation references to chat responses.

[NOTE]
====
The Notebooks feature, which enables you to upload and query your own documents, uses a separate RAG mechanism and is not affected by the OKP integration.
====
