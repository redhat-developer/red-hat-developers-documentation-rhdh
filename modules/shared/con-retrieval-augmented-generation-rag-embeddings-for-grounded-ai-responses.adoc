= Retrieval augmented generation (RAG) embeddings for grounded AI responses

[role="_abstract"]
Use retrieval-augmented generation (RAG) embeddings to ground artificial intelligence (AI) responses in {product-very-short} product documentation and provide verified citations during user interactions.

{product-very-short} {ia-name} uses the Offline Knowledge Portal (OKP) as the RAG backend for product documentation. OKP is a Red Hat curated knowledge base that contains {product-very-short} product documentation optimized for RAG operations. OKP runs as a standalone service alongside the {ia-brand-name} installation.

The {lcs-name} ({lcs-short}) uses OKP as a RAG tool during inference to retrieve relevant {product-very-short} documentation and attaches documentation references to chat responses.

OKP is optional and disabled by default on all platforms. The OKP image is large, so enabling it can significantly increase the time of the first installation while the image is downloaded. How you enable OKP depends on your deployment method:

* With the {product} Operator, enable the `intelligent-assistant-okp` add-on flavour alongside the base `intelligent-assistant` flavour. On {ocp-short}, the Operator automatically creates the OKP `Deployment`, `Service`, and `Route`, and sets the OKP service URL for the {lcs-short} sidecar. On other Kubernetes platforms, the Operator deploys OKP, but you must provide the registry credentials, Ingress, TLS, and OKP service URL yourself, because the Operator does not manage Ingress.
* With the Helm chart, set `intelligentAssistant.okp.enabled` to `true`. On {ocp-short}, the chart creates the OKP `Route` automatically. On other Kubernetes platforms, you must also enable and configure `intelligentAssistant.okp.ingress`.

When OKP is not enabled, the assistant runs without a knowledge base: general chat still works, but product-specific responses might be less accurate.

[NOTE]
====
The Notebooks feature, which enables you to upload and query your own documents, uses a separate RAG mechanism and is not affected by the OKP integration.
====
