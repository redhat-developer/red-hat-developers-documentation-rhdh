= Quicklinks and starred items in the global header

[role="_abstract"]
In {product-very-short} 2.1, the global header includes the *Starred Items* drop-down list and the *Quicklinks* application launcher by default. You do not need to configure dynamic plugin `mountPoints` to display them.

The global header provides the `gh-component:global-header/starred-dropdown` and `gh-component:global-header/app-launcher-dropdown` extensions. The application launcher includes links to the {product-short} documentation and {product-local-very-short} by default.

To add a link to the application launcher, configure `globalHeader.menuItems` in your `{my-app-config-file}` file. For example:

[source,yaml]
----
globalHeader:
  menuItems:
    - target: app-launcher
      title: Internal Wiki
      icon: article
      link: https://wiki.example.com
      sectionLabel: Resources
      priority: 80
----

If these controls are missing after an upgrade, check whether your dynamic plugin configuration disables the global header.
