[NOTE]
====
The `disabled` field is deprecated in {product-short} 2.1 and will be removed in {product-short} 2.3.
Use the `enabled` field for all plugin configurations.

To migrate your configuration:

* Replace `disabled: false` with `enabled: true` to activate a plugin.
* Replace `disabled: true` with `enabled: false` to deactivate a plugin.

For detailed migration instructions, see xref:migrate-disabled-to-enabled-field[].
====
