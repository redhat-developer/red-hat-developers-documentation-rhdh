= Old front-end system: additional utility APIs

[role="_abstract"]
In the old front-end system, `createApp` received plugin objects exported by `createPlugin`. It registered the plugin's API factories for use in the front-end application.

[IMPORTANT]
====
The `dynamicPlugins.frontend` configuration from the old front-end system (OFS) does not apply to {product} 2.1. This page describes the former capability; it does not provide a 2.1 procedure for this customization.

For documented configuration changes, see {configuring-book-link}#configuration-key-mapping-from-old-to-new-front-end-system_migrate-to-the-front-end-system-to-use-blueprint-based-dynamic-routing[Configuration key mapping from old to new front-end system]. If you develop custom plugins, see {configuring-book-link}#migrate-custom-plugins-to-ensure-compatibility-after-upgrade_migrate-to-the-front-end-system-to-use-blueprint-based-dynamic-routing[Migrate custom plugins to ensure compatibility after upgrade].
====
