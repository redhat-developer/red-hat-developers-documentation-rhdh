= Export and package an NFS plugin for dynamic loading

[role="_abstract"]
Use the {product-very-short} 2.1 CLI to export a custom plugin for the new front-end system (NFS) and package it as an OCI image. The CLI generates standard module federation assets and NFS feature metadata without a `dist-scalprum` directory or callback manifest.

.Prerequisites
* Your front-end plugin uses NFS and default-exports a plugin created with `createFrontendPlugin` from a package entry point. A plugin generated by the 2.1 CLI uses the package root; an existing migrated plugin can use `./alpha`. For migration instructions, see {configuring-book-link}#migrate-custom-plugins-to-ensure-compatibility-after-upgrade_migrate-to-the-front-end-system-to-use-blueprint-based-dynamic-routing[Migrate custom plugins to ensure compatibility after upgrade].
* You have access to an OCI registry and a container tool such as Podman.
* `bash`, `npm` 7 or later, and `tar` are available on your `PATH` for the CLI packaging step.
* Your plugin does not contain old `scalprum` package metadata or stale `dist-scalprum/` output.

The 2.1 CLI does not support Scalprum assets.

Replace _<your_namespace>_ in the image reference with your registry namespace.

.Procedure
. From the plugin package root, export the dynamic plugin:
+
[source,terminal,subs="+quotes"]
----
$ *npx @red-hat-developer-hub/cli@2.1.0 plugin export*
----
+
The export creates `dist-dynamic/`. For a front-end plugin, the standard module federation output includes `dist-dynamic/dist/remoteEntry.js`. The generated package metadata includes `backstage.features` for NFS discovery.
. Package the exported plugin as an OCI image:
+
[source,terminal,subs="+quotes"]
----
$ *npx @red-hat-developer-hub/cli@2.1.0 plugin package --tag quay.io/_<your_namespace>_/simple-example:v1*
----
. Log in to the registry:
+
[source,terminal,subs="+quotes"]
----
$ *podman login quay.io*
----
. Push the image to your registry:
+
[source,terminal,subs="+quotes"]
----
$ *podman push quay.io/_<your_namespace>_/simple-example:v1*
----
