= Verify the deployed vector store

[role="_abstract"]
Confirm that {ia-short} can read the delivered artifacts, that the BYOK source is registered, and that the assistant retrieves and cites content from your custom documentation.

.Prerequisites
* You have registered the store as described in xref:configure-byok-rag-by-using-the-helm-chart_{context}[Configure BYOK RAG by using the Helm chart], xref:configure-byok-rag-by-using-the-operator_{context}[Configure BYOK RAG by using the Operator], or xref:deploy-byok-rag-in-a-disconnected-environment_{context}[Deploy BYOK RAG in a disconnected environment].
* You have applied the configuration and restarted or rolled out the {ia-short} workload so that it receives both the configuration and the database.

.Procedure

. Verify the following conditions after deployment:
+
--
.. The init container or file-delivery process completes successfully.
.. The {ia-short} container can read the configured `faiss_store.db` path.
.. The {ia-short} container can read the local embedding model files, including `model.safetensors`, the tokenizer, and model configuration.
.. The {ia-short} readiness endpoint reports success.
.. The BYOK source appears in the RAG and vector-store API responses.
.. The {ia-short} answers a distinctive question from the custom documents and displays the expected source metadata.
--

. From inside the {ia-short} container, run the following example checks:
+
[source,terminal]
----
$ test -r /rag-content/embeddings_model/model.safetensors
$ test -r /rag-content/vector_db/custom_docs/faiss_store.db
$ curl --fail http://127.0.0.1:8080/readiness
$ curl --fail http://127.0.0.1:8080/v1/rags
$ curl --fail http://127.0.0.1:8080/v1/vector-stores
----
+
The exact host and port can differ depending on the installation. Protect administrative and diagnostic endpoints according to your organization's security requirements.

. In the {ia-short}, ask a question whose answer appears only in the custom content. Confirm both the answer and the cited title or URL.
+
[NOTE]
====
A plausible answer without the expected retrieval source does not prove that BYOK retrieval occurred.
====
