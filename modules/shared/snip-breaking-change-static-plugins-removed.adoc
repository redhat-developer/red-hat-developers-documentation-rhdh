{product} {product-version} removes all static plugins from app-next and backend packages.
If you have a custom build with modified `App.tsx` or `backend/src/index.ts` files, you must migrate to dynamic plugin loading before upgrading.
See xref:migrate-from-static-to-dynamic-plugin-loading_{context}[Migrate custom builds to load plugins dynamically] for migration instructions.
====
