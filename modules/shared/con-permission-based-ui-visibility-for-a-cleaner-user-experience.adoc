= Permission-based UI visibility for a cleaner user experience

[role="_abstract"]
To keep the {product-very-short} interface clean and secure, hide the pages, tabs, and navigation items that users cannot open based on their role-based access control (RBAC) permissions.

By default, users can see navigation links, sidebar items, and tabs even when they lack the permissions to open the content behind them. These links lead to empty states or 403 errors that clutter the interface, cause confusion, and can expose the names of tools and features that users cannot use.

With RBAC-based visibility control, {product} ({product-very-short}) evaluates each user's roles and permissions, so each user sees only the pages, tabs, and navigation items that they are authorized to access. The interface adapts to each role, giving users a cleaner workspace focused on the tasks they can complete.
