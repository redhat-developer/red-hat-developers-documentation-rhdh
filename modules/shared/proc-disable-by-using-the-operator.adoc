= Disable {ia-name} by using the Operator

[role="_abstract"]
Disable the {ia-name} chat interface and stop associated container processes to remove the service from your Operator-backed deployment.

.Prerequisites
* You have access to the cluster where your instance is deployed.
* You have cluster administrator privileges.

.Procedure

. Open your {backstage} custom resource (CR) YAML file.
. In the `spec` section, set the `enabled` flag to `false` for the `intelligent-assistant` flavour. This disables the chat interface and prevents the Operator from injecting unconfigured sidecar containers:
+
[source,yaml,subs="+attributes,+quotes"]
----
apiVersion: rhdh.redhat.com/v1alpha5
kind: {product-custom-resource-type}
metadata:
  name: intelligent-assistant-disabled
spec:
  flavours:
    - name: intelligent-assistant
      enabled: false
----
. Apply the updated custom resource manifest to your cluster:
+
[source,bash]
----
oc apply -f <backstage_cr_file>.yaml
----

.Verification
. Log in to your console instance.
. Verify that the *Intelligent Assistant* button no longer appears on the home page.
