= Install {product-cli} to run operations from your terminal

[role="_abstract"]
To run {product} ({product-very-short}) operations from your terminal, install {product-cli}, the command-line interface (CLI) for {product-very-short}, from the npm registry.

.Prerequisites
* You have installed Node.js and the `npm` package manager.
* Your workstation can reach the public npm registry.

.Procedure
* Install {product-cli} globally:
+
[source,terminal]
----
$ npm install -g @red-hat-developer-hub/cli
----
+
To run the CLI without a global installation, prefix each command with `npx @red-hat-developer-hub/cli` instead.

.Verification
* Confirm that the CLI is available:
+
[source,terminal]
----
$ rhdh-cli --help
----
