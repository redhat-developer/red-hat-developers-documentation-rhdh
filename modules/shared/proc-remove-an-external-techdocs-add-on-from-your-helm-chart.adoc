= Remove an external TechDocs add-on from your Helm chart

[role="_abstract"]
Disable or permanently remove an external TechDocs add-on from your {product} Helm chart when you no longer need it.

Whether a plugin is enabled is controlled at the plugin level, so disabling the plugin disables all of the TechDocs add-ons in the disabled plugin package.

.Procedure
* Perform one of the following actions depending on your goal:
** To temporarily disable all of the TechDocs add-ons in a particular plugin package, in the `plugins` section of the Helm chart, change the value of the `enabled` field to `false`. For example:
+
[source,yaml,subs="+quotes,+attributes"]
----
dynamicPlugins:
  plugins:
    - package: ref://backstage-plugin-techdocs-module-addons-contrib
      enabled: false
----
** To remove an individual TechDocs add-on while keeping the rest of the package enabled, set its extension ID to `false` in the `app.extensions` section of your application configuration. For example:
+
[source,yaml,subs="+quotes,+attributes"]
----
app:
  extensions:
    - addon:techdocs/_<external_techdocs_add-on>_: false
----
+
where:

_<external_techdocs_add-on>_:: Specifies the extension name of the external TechDocs add-on that you want to remove, for example, `text-size`.
+
[NOTE]
====
In {product} {product-version}, the new front-end system no longer uses the `dynamicPlugins.frontend.<plugin>.techdocsAddons` wiring. You disable individual add-ons by their extension ID in the `app.extensions` section.
====
