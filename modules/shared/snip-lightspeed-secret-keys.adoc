:_mod-docs-content-type: SNIPPET
[IMPORTANT]
====
The Secret supplies only provider credentials and endpoints. To enable an inference provider, define it as an entry under the `inference.providers` section of the `lightspeed-stack.yaml` file. Adding a credential key to the Secret does not enable a provider on its own.
====
+
|===
| Key | Description

| `VLLM_URL`
| Specifies the target API endpoint URL for vLLM. The URL must end in `/v1`, for example, `https://<api_endpoint>/v1`.

| `VLLM_API_KEY`
| Stores the authorization token for your vLLM platform.

| `OPENAI_API_KEY`
| Stores the authorization secret key for OpenAI.

| `VERTEX_AI_PROJECT`
| Specifies your {gcp-brand-name} project ID.

| `VERTEX_AI_LOCATION`
| Specifies your target {gcp-brand-name} region.

| `GOOGLE_APPLICATION_CREDENTIALS`
| Specifies the in-container file path of your mounted {gcp-brand-name} service account credentials JSON file.

| `ENABLE_VALIDATION`
| Enables the question-validity shield when set to `question_validity`. Leave the variable unset, or set it to `__disabled__`, to keep validation disabled. A nonempty value such as `true` does not enable the shield.

| `VALIDATION_PROVIDER`
| Specifies the inference provider that runs the classification. The value must match the `id` of a provider that is enabled in `inference.providers`, for example, `openai-primary`.

| `VALIDATION_MODEL_NAME`
| Specifies the model that classifies each prompt, for example, `gpt-4o-mini`.
|===
