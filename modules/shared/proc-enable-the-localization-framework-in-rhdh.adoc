= Enable the localization framework in {product-short}

[role="_abstract"]
Enabling localization enhances accessibility, improves the user experience for a global audience, and assists organizations in meeting language requirements in specific regions.

As an administrator, you enable the localization framework and select which languages users can choose. {product} {product-version} uses the new front-end system, so you configure language selection with the `api:app/app-language` extension in the `app.extensions` section of your configuration file.
The following languages are supported:

* English (en)
* French (fr)
* German (de)
* Italian (it)
* Japanese (ja)
* Spanish (es)

[NOTE]
====
The default language for {product-very-short} is English.
====

.Procedure
* Add the `api:app/app-language` extension to the `app.extensions` section of your custom {product-short} `{my-app-config-file}` configuration file to define the languages that users can select:
+
[id="app-language"]
.`{my-app-config-file}` fragment with language selection configuration
[source,yaml,subs="+quotes"]
----
app:
  extensions:
    - api:app/app-language:
        config:
          availableLanguages: # List of languages that users can select. Must include `en`, otherwise the translation framework fails to load.
            - en
            - fr
            - de
            - it
            - ja
            - es
          defaultLanguage: en # Optional. Defaults to `en` if not specified.
----
