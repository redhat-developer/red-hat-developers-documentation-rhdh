= Mirror {ia-name} images for air-gapped environments

[role="_abstract"]
Mirror the required {ia-name} container images and plugins to your local registry to provide chat assistance in an air-gapped environment. 

The {installing-in-air-gap-book-link}#install-rhdh-in-a-fully-disconnected-environment-with-the-operator_install-rhdh-in-an-air-gapped-environment-with-the-operator[`prepare-restricted-environment.sh`] script does not automatically parse `{ia-name}` images from the bundle manifest, so mirror these images manually before running the script.

.Prerequisites
* You have a target mirror registry accessible to your disconnected cluster.
* You authenticated to the {rhcr} and your target mirror registry.
* You have configured image pull authentication for your mirror registry as described in {installing-in-air-gap-book-link}#install-rhdh-in-an-air-gapped-environment-with-the-operator[Install {product} in an air-gapped environment with the Operator]. The `kubelet` requires these credentials to pull all {product} container images, including the {ia-name} sidecar images.

.Procedure

. Extract the deployment configurations from the official Operator bundle. The {lcs-short} sidecar image is defined in the `intelligent-assistant` flavour config map, and the OKP image is defined in the plugin dependencies config map:
+
[source,terminal,subs=+attributes]
----
BUNDLE_IMAGE="registry.redhat.io/rhdh/rhdh-operator-bundle:{product-version}"
CONTAINER_ID=$(podman create "${BUNDLE_IMAGE}")
podman cp $CONTAINER_ID:/manifests/rhdh-flavour-intelligent-assistant-config_v1_configmap.yaml ./lightspeed-config.yaml
podman cp $CONTAINER_ID:/manifests/rhdh-plugin-deps_v1_configmap.yaml ./plugin-deps-config.yaml
podman rm $CONTAINER_ID
----

. Identify the {lcs-short} and OKP container image tags from the extracted configuration files:
+
[source,terminal]
----
LS_CORE_IMAGE=$(yq '.data["deployment.yaml"]' lightspeed-config.yaml | yq '.spec.template.spec.containers[] | select(.name == "lightspeed-core") | .image')
LS_OKP_IMAGE=$(yq '.data["okp.yaml"]' plugin-deps-config.yaml | yq 'select(.kind == "Deployment") | .spec.template.spec.containers[] | select(.name == "okp") | .image' | head -1)
----
+
[NOTE]
====
OKP is an optional add-on that is disabled by default. Mirror the OKP image only if you intend to enable the `intelligent-assistant-okp` flavour.
====

. Mirror the images to your internal registry by running the `skopeo copy` command:
+
[source,terminal]
----
skopeo copy docker://${LS_CORE_IMAGE} docker://<mirror_registry>/<ls_core_repo>@<digest>
skopeo copy docker://${LS_OKP_IMAGE} docker://<mirror_registry>/<ls_okp_repo>@<digest>
----
