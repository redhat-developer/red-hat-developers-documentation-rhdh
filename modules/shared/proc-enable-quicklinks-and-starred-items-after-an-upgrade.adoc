= Enable Quicklinks and starred items after an upgrade

[role="_abstract"]
If *Quicklinks* or *Starred Items* are missing after upgrading to {product-very-short} 2.1, check your dynamic plugin overrides. The Global Header plugin and these controls are enabled by default in 2.1, but an existing override can leave the plugin disabled.

.Prerequisites

* You have access to your dynamic plugin configuration.
* You can update the configuration through the Operator or Helm chart.

.Procedure

. Find the `red-hat-developer-hub-backstage-plugin-global-header` entry in your dynamic plugin configuration.
. If the entry disables the plugin, remove the override or enable the plugin. For example, use the following `dynamic-plugins.yaml` configuration:
+
[source,yaml]
----
includes:
  - dynamic-plugins.default.yaml

plugins:
  - package: ref://red-hat-developer-hub-backstage-plugin-global-header
    enabled: true
----
+
The `ref://` package resolves against the default catalog included in {product-very-short} 2.1.

. Remove any `mountPoints` configuration for the Global Header plugin that you carried forward from earlier releases. The 2.1 plugin supplies *Quicklinks* and *Starred Items* through front-end extensions.
. Apply the configuration by updating the Operator ConfigMap or upgrading the Helm release.

.Verification

. Restart {product-very-short} if your deployment does not restart automatically.
. Confirm that the *Starred Items* drop-down list and *Quicklinks* application launcher appear in the global header.
