= Disable the quick start

[role="_abstract"]
You can disable the quick start plugin if you do not want to use guided onboarding steps in your {product-short} instance. 

.Procedure

* To disable the quick start plugin, set the disabled property to `true` as shown in the following code:
+
[source,yaml]
----
global:
  dynamic:
    includes:
      - dynamic-plugins.default.yaml
    plugins:
      # Replace <oci_reference_for_...> with the current value from the GA plugins reference table.
      - package: <oci_reference_for_red_hat_developer_hub_backstage_plugin_quickstart>
        disabled: true
----
