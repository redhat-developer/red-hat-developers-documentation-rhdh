= Create an NFS plugin development project

[role="_abstract"]
Create a standalone, version-pinned front-end plugin project for {product} 2.1. The {product-very-short} CLI generates a plugin for the new front-end system (NFS) and a local development harness without an old {backstage} application.

.Prerequisites
* You have Node.js 22 and Yarn 4 available.

.Procedure
. Create a workspace directory:
+
[source,terminal,subs="+quotes"]
----
$ *mkdir rhdh-plugin-dev*
----
. Change to the new directory:
+
[source,terminal,subs="+quotes"]
----
$ *cd rhdh-plugin-dev*
----
. Generate a front-end plugin for {product} 2.1:
+
[source,terminal,subs="+quotes"]
----
$ *npx @red-hat-developer-hub/cli@2.1.0 plugin new simple-example --type frontend --rhdh-version 2.1.0*
----
+
The CLI pins the project's {backstage} dependencies to the selected {product-very-short} release.
. Change to the plugin directory:
+
[source,terminal,subs="+quotes"]
----
$ *cd simple-example*
----
. Install the plugin dependencies:
+
[source,terminal,subs="+quotes"]
----
$ *yarn install*
----

.Verification
The `simple-example/` directory has `package.json`, `src/`, `dev/`, and `backstage.json`. The `dev/` directory has the NFS development harness.
