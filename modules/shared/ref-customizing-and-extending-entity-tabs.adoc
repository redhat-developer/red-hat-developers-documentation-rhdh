= Customize and extend catalog entity tabs

[role="_abstract"]
You can customize and extend the set of tabs by using the `app.extensions` configuration in your `{my-app-config-file}` file.

[NOTE]
====
{product} {product-version} uses the `app.extensions` configuration format.
The `dynamicPlugins.frontend.entityTabs` format used in previous versions is no longer supported.
====

== Configure entity tabs in app.extensions

Entity tabs are configured as `entity-content` extensions in the `app.extensions` section:

[source,yaml]
----
app:
  extensions:
    # Customize an existing tab title
    - entity-content:catalog/entity/docs:
        config:
          title: "Documentation"

    # Disable an entity tab
    - entity-content:catalog/entity/ci: false

    # Add a new custom tab
    - entity-content:my-plugin/custom-tab:
        config:
          title: "Custom Tab"
          filter: kind:component  # Show only for components
----

== Entity tab configuration parameters

Each entity tab extension supports the following configuration parameters:

* `title`: The title displayed to the user in the tab navigation
* `filter`: Entity filter expression (e.g., `kind:component`, `kind:api,kind:system`)
* `icon`: Icon identifier for the tab (when `showNavItemIcons` is enabled)

Tabs appear in the order they are listed in the `app.extensions` configuration.

== Filter entity tabs by kind or other properties

Use the `filter` parameter to control which entity kinds display specific tabs:

[source,yaml]
----
app:
  extensions:
    # Show API tab only for API and Component entities
    - entity-content:catalog/entity/api:
        config:
          title: "API"
          filter: kind:api,kind:component

    # Show Dependencies tab only for Components
    - entity-content:catalog/entity/dependencies:
        config:
          title: "Dependencies"
          filter: kind:component

    # Show Definition tab only for APIs
    - entity-content:catalog/entity/definition:
        config:
          title: "API Definition"
          filter: kind:api
----

== Configure tab icons

Enable tab icons by configuring `showNavItemIcons` and specifying icon identifiers:

[source,yaml]
----
app:
  extensions:
    # Enable tab icons globally
    - entity-page:catalog/entity-page:
        config:
          showNavItemIcons: true

    # Configure individual tab icons
    - entity-content:catalog/entity/docs:
        config:
          title: "Documentation"
          icon: docs
    - entity-content:catalog/entity/kubernetes:
        config:
          title: "Kubernetes"
          icon: kubernetes
----

== Entity validation message extensions

The entity overview tab supports validation message extensions that plugins contribute through the `EntityCardBlueprint`.
Validation extensions evaluate entity properties and display feedback messages with severity indicators (error, warning, info).

Validation message mount points:

* `entity.page.overview/validation`: Validation message section on the overview tab

Validation extensions use the `entity-card` extension type with the following ID format:

----
entity-card:<plugin-id>/<validation-name>
----

See xref:entity-validation-extensibility_{context}[Display validation feedback on catalog entities] for more information on creating and configuring validation extensions.
