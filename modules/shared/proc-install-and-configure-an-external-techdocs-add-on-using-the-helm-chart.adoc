= Install and configure an external TechDocs add-on using the Helm chart

[role="_abstract"]
You can use a dynamic plugin to import TechDocs add-ons into your TechDocs plugin. If you use the {product} Helm chart to install the dynamic plugin, you can add TechDocs add-ons to the plugin package in your Helm chart.

Preinstalled add-ons, such as `ReportIssue`, are included in the default `backstage-plugin-techdocs-module-addons-contrib` package. In {product} {product-version}, the new front-end system registers these add-ons in code by using `AddonBlueprint` from `@backstage/plugin-techdocs-react/alpha`, and they are enabled by default. You no longer wire them through the `dynamicPlugins.frontend.<plugin>.techdocsAddons` section. To enable or disable a specific add-on, reference its extension ID in the `app.extensions` section of your application configuration.

.Prerequisites
* The TechDocs plugin is installed and enabled.

.Procedure
. In your Helm chart, add the `dynamicPlugins` parameters required to install a dynamic plugin, as shown in {installing-and-viewing-plugins-book-link}#installing-dynamic-plugins-using-the-helm-chart_install-dynamic-plugins-in-rhdh[Installing dynamic plugins using the Helm chart]
+
[NOTE]
====
The default configuration includes the `dynamic-plugins.default.yaml` file, which contains all of the dynamic plugins, including TechDocs add-ons, that are preinstalled in {product}, whether they are enabled or disabled by default.
====
. In your Helm chart, enable the default `backstage-plugin-techdocs-module-addons-contrib` package. For example:
+
[source,yaml,subs="+quotes,+attributes"]
----
dynamicPlugins:
  plugins:
    - package: ref://backstage-plugin-techdocs-module-addons-contrib
      enabled: true
----
+
The add-ons in this package are registered in code and enabled by default. No `techdocsAddons` wiring is required.
. To enable or disable a specific add-on, reference its extension ID in the `app.extensions` section of your application configuration. For example:
+
[source,yaml,subs="+quotes,+attributes"]
----
app:
  extensions:
    - addon:techdocs/_<external_techdocs_add-on>_: true
----
+
where:

_<external_techdocs_add-on>_:: Specifies the extension name of the external TechDocs add-on that you want to enable or disable, for example, `text-size` or `light-box`.
