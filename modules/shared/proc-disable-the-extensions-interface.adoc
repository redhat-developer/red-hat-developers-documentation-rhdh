= Disable the Extensions UI

[role="_abstract"]
The Extensions feature is available by default. To remove the Extensions interface (Marketplace) from your instance, you must disable the relevant plugins.

.Procedure
* Edit your `dynamic-plugins.yaml` with the following content.
+
[source,yaml]
----
plugins:
  # Replace each <oci_reference_for_...> with the current value from the applicable plugins reference table.
  - package: <oci_reference_for_red_hat_developer_hub_backstage_plugin_extensions>
    disabled: true
  - package: <oci_reference_for_red_hat_developer_hub_backstage_plugin_catalog_backend_module_extensions>
    disabled: true
  - package: <oci_reference_for_red_hat_developer_hub_backstage_plugin_extensions_backend>
    disabled: true
----
+
[NOTE]
====
Disabling these plugins removes the *Catalog* and *Installed* tabs. You can still view a basic list of installed plugins by selecting *Administration* > *Extensions*.
====
