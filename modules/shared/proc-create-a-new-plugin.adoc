= Prepare a generated front-end plugin for development

[role="_abstract"]
The {product-very-short} 2.1 CLI generates a front-end plugin with a new front-end system (NFS) development harness. Inspect its entry points before adding pages or entity components.

.Prerequisites
* You have created a plugin project by following xref:create-a-new-application_develop-and-test-new-plugin-components-locally[Create an NFS plugin development project].
* Your current directory is the generated `simple-example/` plugin project.

The development harness is for plugin authoring. When you install the exported plugin in {product}, the application provides its own theme and discovers the plugin's extensions. You do not need to call `createDevApp().addThemes()`.

.Procedure
. Open the generated `simple-example/` project and inspect `package.json`, `src/index.ts`, and `src/plugin.tsx`. The `main` field points to `src/index.ts`, which default-exports the plugin created in `src/plugin.tsx`. The generated package has no `./alpha` export.
. Run the generated development harness:
+
[source,terminal,subs="+quotes"]
----
$ *yarn start*
----
. Open the local URL printed by the command to inspect the generated page.
