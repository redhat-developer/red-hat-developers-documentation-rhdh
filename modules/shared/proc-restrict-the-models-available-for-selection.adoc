= Restrict the models available for selection

[role="_abstract"]
To control which models users can select in the chat dialog, define an `allowlist` for each inference provider in the `lightspeed-stack.yaml` file.

By default, the model selection dropdown menu lists every model that the configured inference provider exposes. To present users with only the functional, user-facing models that your organization approves, restrict this list with an allowlist.

[NOTE]
====
In {product} 2.1 and later, the large language models (LLMs) that you configure through your inference providers perform safety validation, so no dedicated safety model appears in the model selection dropdown menu. Embedding models are also excluded. Use `allowed_models` when you want to narrow the list further to a specific set of approved models.
====

.Prerequisites
* You have access to the `lightspeed-stack.yaml` configuration file for your deployment.

.Procedure
. In the `lightspeed-stack.yaml` file, add the `allowed_models` field under `extra` for each inference provider, and list the models that you want to expose to users:
+
[source,yaml]
----
inference:
  providers:
    - type: openai
      id: openai
      api_key_env: OPENAI_API_KEY
      extra:
        allowed_models:
          - gpt-4o-mini
----
+
where:
+
`allowed_models`:: The list of models that appear in the model selection dropdown menu for that provider. Models that you omit from this list are hidden from users.

. Apply the modified `lightspeed-stack.yaml` file by using a custom ConfigMap:
+
--
ifdef::lightspeed-configure-sections[]
For Operator-based deployments, see xref:configure-by-using-the-operator_configure-to-initialize-the-ai-assistant[Configure the virtual assistant components].

For Helm-based deployments, see xref:configure-by-using-the-helm-chart_configure-to-initialize-the-ai-assistant[Configure {ia-name} by using the Helm chart].
endif::lightspeed-configure-sections[]
ifndef::lightspeed-configure-sections[]
For Operator-based deployments, map the ConfigMap in the `extraFiles` section of the {backstage} custom resource.

For Helm-based deployments, reference the ConfigMap in the `values.yaml` file.
endif::lightspeed-configure-sections[]
--

. Apply the updated configuration to your cluster, and restart the deployment if it does not trigger an automatic rollout.

.Verification
. Log in to your {product-very-short} instance.
. Open the chat dialog and select the model selection dropdown menu.
. Confirm that the dropdown menu lists only the allowed models.
