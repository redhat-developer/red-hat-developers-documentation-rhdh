= {product-cli} for automation and AI agents

[role="_abstract"]
{product-cli} is a command-line interface (CLI) that provides terminal access to {product} ({product-very-short}) catalog, scaffolder, and TechDocs operations to automate repeatable tasks without using the web UI.

The intent-based `catalog`, `api`, `search`, `docs`, and `template` commands can return structured JSON output with the `--output json` flag, and commands set a nonzero exit code on failure. As a result, you can call {product-cli} from scripts, continuous integration pipelines, and AI agents that run operations on your instance.

You can use {product-cli} to complete the following tasks:

* List, inspect, validate, and register catalog entities and APIs.
* Search the catalog, software templates, and TechDocs from one command.
* Run and dry-run software templates to scaffold new components.
* Trigger and read TechDocs builds and coverage.
* Discover and run the actions that your installed plugins expose.

You can query and manage {product-very-short} through {backstage} actions using command groups in intent-based workflows. Additional commands for tasks such as plugin development and packaging are documented separately.

The CLI authenticates against each instance separately, enabling you to target several {product-very-short} instances from the same workstation and switch between them as needed.
