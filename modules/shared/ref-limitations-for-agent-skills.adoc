= Limitations for Agent Skills

[role="_abstract"]
Review the following limitations before you configure Agent Skills for the {ia-short}.

* The {ia-short} user interface does not currently provide a view that lists the available skills. Users can ask the LLM to `List available skills`, and the LLM can respond with the skills available to the deployment.
* Skills are loaded when the `lightspeed-core` container starts. Adding or modifying skill files requires a new {product-very-short} pod.
* Skills must be available on the local file system of the `lightspeed-core` container. The {ia-short} does not retrieve skills directly from a remote URL.
* Skills provide instructions and reference content only. Executable capabilities must be provided separately, for example through Model Context Protocol (MCP) tools.
* Skill names must be unique across all configured paths.
