= Remove an external TechDocs add-on from your ConfigMap

[role="_abstract"]
Disable or permanently remove an external TechDocs add-on from your {product} ConfigMap when you no longer need it.

The `disabled` status is controlled at the plugin level, therefore, disabling the plugin disables all of the TechDocs add-ons in the disabled plugin package.

.Procedure

. From the Developer perspective in the {ocp-short} web console, click *ConfigMaps*.
. From the *ConfigMaps* page, click the ConfigMap that contains the TechDocs add-on that you want to remove.
. Select the *YAML view* option in the *Configure via* field.
. In the config map, complete one of the following actions based on whether you want to disable all of the add-ons in a package or a single add-on:
** To temporarily disable all of the TechDocs add-ons in a particular plugin package, in the `plugins` section, change the value of the `disabled` field to `true`. For example:
+
[source,yaml,subs="+quotes,+attributes"]
----
kind: ConfigMap
apiVersion: v1
metadata:
  name: dynamic-plugins-rhdh
data:
  dynamic-plugins.yaml: |
    includes:
      - dynamic-plugins.default.yaml
    plugins:
      - package: ./dynamic-plugins/dist/backstage-plugin-techdocs-module-addons-contrib
        disabled: true
----
** To remove a single TechDocs add-on while keeping the rest of the package enabled, set its extension ID to `false` in the `app.extensions` section of your application configuration. For example:
+
[source,yaml,subs="+quotes,+attributes"]
----
app:
  extensions:
    - addon:techdocs/_<external_techdocs_add-on>_: false
----
+
where:

_<external_techdocs_add-on>_:: Specifies the extension name of the external TechDocs add-on that you want to remove, for example, `text-size`.
+
[NOTE]
====
In {product} {product-version}, the new front-end system no longer uses the `dynamicPlugins.frontend.<plugin>.techdocsAddons` wiring. You disable individual add-ons by their extension ID in the `app.extensions` section.
====
. Click *Save*.
. In the web console navigation menu, click *Topology* and wait for the {product} pod to start.
. Click the *Open URL* icon to start using the {product} platform with the new configuration changes.
