= Remove unused tabs and cards from entity pages

[role="_abstract"]
Disable entity page tabs and cards that your teams do not use to simplify the catalog interface.
You can hide tabs such as CI, monitoring, or image registry by setting their extensions to false in your `{my-app-config-file}` file.

.Prerequisites

* {product} {product-version} or later is installed with the new front-end system enabled.
* You have access to modify your `{my-app-config-file}` file.

.Procedure

. Identify the extension ID for the tab or card you want to disable.
+
You can find extension IDs using one of the following methods:
+
--
* Check the browser developer tools:
.. Open your {product} instance in a web browser.
.. Navigate to a catalog entity page.
.. Press F12 to open developer tools.
.. Select the Console tab.
.. Type `{backstage}.getExtensions()` and press Enter.
.. Review the list of loaded extensions and note the IDs.

* Consult the plugin documentation for the plugin that provides the tab or card.

* Use common extension ID patterns:
** Entity tabs: `entity-content:<plugin_id>/<tab_name>`
** Entity cards: `entity-card:<plugin_id>/<card_name>`
--

. Edit your `{my-app-config-file}` file and add the extension ID with a value of `false`:
+
[source,yaml]
----
app:
  extensions:
    # Disable CI tab on entity pages
    - entity-content:catalog/entity/ci: false

    # Disable monitoring card on entity overview
    - entity-card:catalog/entity/monitoring-card: false

    # Disable image registry tab
    - entity-content:catalog/entity/image-registry: false
----

. To disable multiple tabs or cards, add each extension on a separate line:
+
[source,yaml]
----
app:
  extensions:
    # Disable unused entity tabs
    - entity-content:catalog/entity/ci: false
    - entity-content:catalog/entity/cd: false
    - entity-content:catalog/entity/lighthouse: false
    - entity-content:catalog/entity/image-registry: false

    # Disable unused entity cards
    - entity-card:catalog/entity/monitoring-card: false
----

. Save the `{my-app-config-file}` file.

. Restart your {product} instance to apply the changes.

.Verification

. Navigate to a catalog entity page in your {product} instance.
. Verify that the disabled tabs no longer appear in the entity page navigation.
. Verify that the disabled cards no longer appear on the entity overview or other tabs.

== Simplify entity pages for API components

To create a streamlined view for API entities that shows only the overview, definition, and documentation tabs:

[source,yaml]
----
app:
  extensions:
    # Disable tabs not relevant to APIs
    - entity-content:catalog/entity/ci: false
    - entity-content:catalog/entity/cd: false
    - entity-content:catalog/entity/kubernetes: false
    - entity-content:catalog/entity/monitoring: false
    - entity-content:catalog/entity/dependencies: false
    - entity-content:catalog/entity/topology: false
----

This configuration leaves only the Overview, Definition, and Docs tabs visible for API entities.
