= Enable the Nexus Repository Manager plugin

[role="_abstract"]
Enable the Nexus Repository Manager plugin to view build artifact details on entity pages in {product-short}.

In {product-very-short} {product-version}, the Nexus Repository Manager plugin uses the new frontend system and provides its *Build Artifacts* entity tab (Development group) by default. You do not need to configure frontend mount points.

[NOTE]
====
The *Build Artifacts* tab appears only when the entity has the Nexus Repository Manager annotations, for example `nexus-repository-manager/docker.image-name`. The new frontend system filters the tab with `isNexusRepositoryManagerExperimentalAvailable`, so enabling the plugin alone does not display the tab on entities that are not annotated. To add these annotations, see xref:configure-the-nexus-repository-manager-plugin_{context}[Configuring the Nexus Repository Manager plugin].
====

.Prerequisites
* You have a running Nexus Repository Manager instance.

.Procedure
* Add the following configuration to your `dynamic-plugins.yaml` file to enable the plugin:
+
[source,yaml,subs="+quotes"]
----
plugins:
  - package: oci://ghcr.io/redhat-developer/rhdh-plugin-export-overlays/backstage-community-plugin-nexus-repository-manager:__<tag>__
    enabled: true
----
+
