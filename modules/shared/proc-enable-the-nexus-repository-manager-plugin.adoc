= Enable the Nexus Repository Manager plugin

[role="_abstract"]
Enable the Nexus Repository Manager plugin to view build artifact details on entity pages in {product-short}.

In {product-very-short} {product-version}, the Nexus Repository Manager plugin uses the new frontend system and provides its *Image Registry* entity tab card by default. You do not need to configure frontend mount points.

.Prerequisites
* You have a running Nexus Repository Manager instance.

.Procedure
* Add the following configuration to your `dynamic-plugins.yaml` file to enable the plugin:
+
[source,yaml,subs="+quotes"]
----
plugins:
  - package: oci://ghcr.io/redhat-developer/rhdh-plugin-export-overlays/backstage-community-plugin-nexus-repository-manager:__<tag>__
    disabled: false
----
+
