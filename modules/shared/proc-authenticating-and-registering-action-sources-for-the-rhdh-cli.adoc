= Authenticate and register action sources to run commands on an instance

[role="_abstract"]
To run commands against a {product} ({product-very-short}) instance, sign in with {product-cli} and register the plugin action sources for the command-line interface (CLI) to use.

The CLI stores credentials and registered action sources per instance. Repeat these steps for each target instance.

.Prerequisites
* You are running {product} ({product-very-short}) 2.1 or later.
* You have installed {product-cli} 2.0.9 or later.
* You have configured your instance to support the CLI authentication flows.
* You have the back-end URL of your {product-very-short} instance.

.Procedure
. Sign in to your instance:
+
[source,terminal]
----
$ rhdh-cli auth login --backend-url https://rhdh.example.com
----
+
Complete the OAuth2 consent flow in your browser when prompted.

. Confirm the active instance:
+
[source,terminal]
----
$ rhdh-cli auth show
----

. Register each plugin action source that you want to use. For example, to register the catalog, scaffolder, search, and authentication sources, run:
+
[source,terminal]
----
$ rhdh-cli actions sources add catalog
$ rhdh-cli actions sources add scaffolder
$ rhdh-cli actions sources add search
$ rhdh-cli actions sources add auth
----
+
Register additional sources, such as `notifications`, only after you install the corresponding plugins on your instance.

.Verification
* List the registered action sources:
+
[source,terminal]
----
$ rhdh-cli actions sources list
----
