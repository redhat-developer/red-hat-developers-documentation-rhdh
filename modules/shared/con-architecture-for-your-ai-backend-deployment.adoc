= {ls-brand-name} architecture for your AI backend deployment

[role="_abstract"]
You can plan your AI backend deployment by understanding how {ls-short} uses the {lcs-name} ({lcs-short}) container to connect {product-very-short} with your large language model (LLM) providers.

The {lcs-short} container serves as the sole integration layer between {product-very-short} and your AI backend services. All LLM inference, tool calling, safety, and retrieval-augmented generation (RAG) requests pass through {lcs-short}, which runs as a sidecar container alongside {product-very-short}.

By default, {product-very-short} displays the {ls-short} interface as a floating action button (FAB) on all platforms.
