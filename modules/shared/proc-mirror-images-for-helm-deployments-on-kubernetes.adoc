= Mirror {ia-name} images for Helm deployments on Kubernetes

[role="_abstract"]
Isolate image references, copy them manually to your internal registry, and update your configuration file when deploying the Helm chart on non-{platform-generic} platforms.

.Prerequisites
* You have a target mirror registry accessible to your disconnected cluster.
* You authenticated to the {rhcr} and your target mirror registry.
* You have configured image pull authentication for your mirror registry as described in {installing-in-air-gap-book-link}#install-rhdh-on-a-supported-kubernetes-platform-in-an-air-gapped-environment-with-the-helm-chart[Install {product} on a supported Kubernetes platform in an air-gapped environment with the Helm chart]. The `kubelet` requires these credentials to pull all {product} container images, including the {ia-name} sidecar images.

.Procedure

. Extract the image references from the default values file of the chart:
+
[source,terminal,subs=+attributes]
----
$ helm show values redhat-developer-hub --repo https://charts.openshift.io/ --version {product-chart-version} > values.default.yaml

LS_OKP_REGISTRY=$(yq -r '.intelligentAssistant.okp.image.registry' values.default.yaml)
LS_OKP_REPOSITORY=$(yq -r '.intelligentAssistant.okp.image.repository' values.default.yaml)
LS_OKP_DIGEST=$(yq -r '.intelligentAssistant.okp.image.digest' values.default.yaml)
LS_OKP_IMAGE="${LS_OKP_REGISTRY}/${LS_OKP_REPOSITORY}"

LS_CORE_REGISTRY=$(yq -r '.intelligentAssistant.core.image.registry' values.default.yaml)
LS_CORE_REPOSITORY=$(yq -r '.intelligentAssistant.core.image.repository' values.default.yaml)
LS_CORE_DIGEST=$(yq -r '.intelligentAssistant.core.image.digest' values.default.yaml)
LS_CORE_IMAGE="${LS_CORE_REGISTRY}/${LS_CORE_REPOSITORY}"
----

. Mirror the images to your internal mirror registry:
+
[source,terminal]
----
skopeo copy --all docker://${LS_OKP_IMAGE}@${LS_OKP_DIGEST} docker://<mirror_registry_name>/<ls_okp_repo_name>@${LS_OKP_DIGEST}
skopeo copy --all docker://${LS_CORE_IMAGE}@${LS_CORE_DIGEST} docker://<mirror_registry_name>/<ls_core_repo_name>@${LS_CORE_DIGEST}
----

. Update your custom Helm values file with the mirrored registry locations and plugin references. Mirror the dynamic plugins to the local registry before you add their package paths to the file. For mirroring instructions, see {installing-and-viewing-plugins-book-link}#mirror-rhdh-dynamic-plugins-in-disconnected-environments_install-dynamic-plugins-in-rhdh[Mirroring {product} dynamic plugins in disconnected environments]:
+
[source,yaml]
----
intelligentAssistant:
  enabled: true
  core:
    image:
      registry: <mirror_registry_name>
      repository: <ls_core_repo_name>
      tag: ""
      digest: <ls_core_digest>
  okp:
    enabled: true
    image:
      registry: <mirror_registry_name>
      repository: <ls_okp_repo_name>
      tag: ""
      digest: <ls_okp_digest>
    ingress:
      enabled: true
      host: <okp_ingress_host>
  plugins:
    - package: "oci://<mirror_registry_name>/rhdh/red-hat-developer-hub-backstage-plugin-intelligent-assistant@<ls_frontend_digest>"
      enabled: true
    - package: "oci://<mirror_registry_name>/rhdh/red-hat-developer-hub-backstage-plugin-intelligent-assistant-backend@<ls_backend_digest>"
      enabled: true
----
+
[NOTE]
====
OKP is disabled by default. On non-{platform-generic} platforms, enable it by setting `intelligentAssistant.okp.enabled` to `true` and configuring `intelligentAssistant.okp.ingress` with an Ingress host.
====
