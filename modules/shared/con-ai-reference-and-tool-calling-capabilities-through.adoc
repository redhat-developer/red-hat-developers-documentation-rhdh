= AI reference and tool-calling capabilities through {lcs-name}

[role="_abstract"]
Review the core components managed by the {lcs-name} ({lcs-short}) sidecar container to plan integrations with large language models (LLM) and tool runtime providers.

The {lcs-short} container deploys as a sidecar to extend {product-very-short} functionality, and it integrates and manages the following core components:

* Large language model (LLM) inference providers
* Model Context Protocol (MCP) or Retrieval Augmented Generation (RAG) tool runtime providers
+
[IMPORTANT]
====
Verify that your model supports tool calling before you enable MCP features. Using an incompatible model results in error messages.
====
* Safety providers
* Vector database settings

{lcs-short} also manages the following operational data:

* User feedback collection
* MCP server configuration
* Chat history

All prompts and LLM responses pass through the {lcs-short} sidecar.
