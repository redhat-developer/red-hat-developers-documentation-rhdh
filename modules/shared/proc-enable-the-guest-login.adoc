= Enable the Guest login

[role="_abstract"]
To allow users to log in as a guest on the login page, enable the guest login option.

// EDITOR NOTE (RHIDP-5489, pending engineer confirmation): confirm the guest provider's exact 2.1 config keys against upstream Backstage guest-provider docs referenced in the engineers' draft.

.Procedure

. Install the guest authentication provider dynamic plugin.
For more information, see {authentication-book-link}#authentication-provider-dynamic-plugin-packages_enable-authentication-with-your-identity-provider[the authentication provider dynamic plugin packages reference].

. In the `{my-app-config-file}` file, add the user entity reference to resolve and enable the `dangerouslyAllowOutsideDevelopment` option, as shown in the following example:
+
[source,yaml,subs="+attributes,+quotes"]
----
auth:
  environment: development
  providers:
    guest:
      userEntityRef: user:default/guest
      dangerouslyAllowOutsideDevelopment: true
----
+
[NOTE]
====
The `dangerouslyAllowOutsideDevelopment` option is only relevant when the authentication environment is `development`.
You can use `user:default/guest` as the default user entity reference for the guest user.
====

. Restart the {product-short} application to apply the changes.

.Verification

. Go to the login page of your {product-short} instance.

. Verify that the option to log in as a guest is available.
