= Enable the Guest login

[role="_abstract"]
To allow users to log in as a guest on the login page, enable the guest login option.

.Procedure

. Enable the guest authentication provider plugin in your `dynamic-plugins.yaml` file:
+
[source,yaml]
----
plugins:
  - package: oci://quay.io/rhdh/backstage-plugin-auth-backend-module-guest-provider:{{inherit}}
    enabled: true
----

. In the `{my-app-config-file}` file, add the `auth.providers.guest` entry, as shown in the following example:
+
[source,yaml,subs="+attributes,+quotes"]
----
auth:
  environment: development
  providers:
    guest:
      userEntityRef: user:default/guest
      dangerouslyAllowOutsideDevelopment: true
----
+
[NOTE]
====
`auth.providers.guest` can be an empty object (`guest: {}`).
Both `userEntityRef` (defaults to `user:default/guest`) and `dangerouslyAllowOutsideDevelopment` are optional.
The `dangerouslyAllowOutsideDevelopment` option is only relevant when the authentication environment is NOT `development`.
====

. Restart the {product-short} application to apply the changes.

.Verification

. Go to the login page of your {product-short} instance.

. Verify that the option to log in as a guest is available.
