= Test an NFS plugin in its development harness

[role="_abstract"]
The front-end project generated by the {product-very-short} 2.1 CLI includes a local development harness for the new front-end system (NFS). Use it to inspect the generated page while you develop the plugin.

.Prerequisites
* You have created an NFS front-end plugin project by following xref:create-a-new-application_develop-and-test-new-plugin-components-locally[Create an NFS plugin development project].
* Your current directory is the generated `simple-example/` plugin project.

The generated development harness uses the new front-end system. It does not require `createDevApp().addPage()` or other old front-end system registration. To verify an entity card with a real Catalog entity and to test the exported package in {product-local-very-short}, see xref:verify-plugins-locally_develop-custom-dynamic-plugins-to-support-custom-workflows[Verify plugins locally].

.Procedure
. Start the development harness:
+
[source,terminal,subs="+quotes"]
----
$ *yarn start*
----
. Open the local URL printed by the command and verify that the plugin page renders.
. After editing the plugin source, refresh the page to inspect the change.
