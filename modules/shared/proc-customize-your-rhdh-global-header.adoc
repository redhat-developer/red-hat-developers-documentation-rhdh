= Customize your {product} global header

[role="_abstract"]
Customize the global header in {product-very-short} 2.1 by adding toolbar buttons and menu links in `{my-app-config-file}`, or by changing the built-in front-end extensions. The Global Header plugin is enabled by default.

.Prerequisites

* You can edit the `{my-app-config-file}` file for your {product-very-short} instance.

.Procedure

. Add toolbar buttons or drop-down menu links in the `globalHeader` section of `{my-app-config-file}`. For example:
+
[source,yaml]
----
globalHeader:
  components:
    - title: Platform dashboard
      icon: dashboard
      link: /dashboard
      priority: 75
  menuItems:
    - target: app-launcher
      title: Internal Wiki
      icon: article
      link: https://wiki.example.com
      sectionLabel: Resources
      priority: 80
----
+
For `menuItems.target`, use `app-launcher`, `help`, or `profile`. Higher `priority` values display before lower values.

. Optional: To reorder or hide a built-in header item, configure its extension ID under `app.extensions`. For example:
+
[source,yaml]
----
app:
  extensions:
    - gh-component:global-header/search:
        config:
          priority: 50
    - gh-component:global-header/notification-button:
        disabled: true
----
+
The example moves the search component after items with higher priorities and hides the notification button. Remove these overrides to restore the default behavior.

. Apply your updated application configuration and restart {product-very-short}.

.Verification

. Confirm that the custom toolbar button and application launcher link appear in the global header.
. If you changed built-in extensions, verify their order and visibility.
