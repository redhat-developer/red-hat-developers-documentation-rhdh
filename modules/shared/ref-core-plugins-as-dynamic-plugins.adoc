= Core plugins loaded as dynamic plugins in {product} {product-version}

[role="_abstract"]
{product} {product-version} loads core platform plugins as dynamic plugins through the new front-end system.
This enables consistent configuration and runtime control of all plugins through the `app.extensions` section of your `{my-app-config-file}` file.

== Configuration requirements

Auto-enabled plugins:: Load automatically when {product} starts. You can customize their behavior through the `app.extensions` section but do not need to explicitly enable them.

Plugins requiring configuration:: Must be explicitly configured in the `app.extensions` section to load. The home plugin requires configuration to specify the landing page path and widget layout.

== Relationship to new front-end system

Core plugins use extension blueprints to expose their UI contributions:

* **EntityCardBlueprint**: Contributes cards to entity page sections
* **EntityContentBlueprint**: Contributes tabs to entity pages
* **PageBlueprint**: Contributes new pages and routes to the application
* **SettingsTabBlueprint**: Contributes tabs to the user settings page

You control which extensions load and how they behave through the `app.extensions` configuration section.

== Verify that a core plugin is loaded

Check the backend logs for plugin loading messages:

[source,terminal]
----
$ oc logs deployment/<rhdh-deployment-name> -n <namespace> | grep "plugin-"
----

For frontend plugins, open the browser console and check for plugin loading messages:

. Press F12 to open developer tools.
. Navigate to the Console tab.
. Type `Backstage.getExtensions()` and press Enter.
. Review the list of loaded extensions.

Core plugins should appear in the extension list if they loaded successfully.

== Example configuration for core plugins

== Customize catalog plugin entity tabs
[source,yaml]
----
app:
  extensions:
    # Disable unused catalog entity tabs
    - entity-content:catalog/entity/ci: false
    - entity-content:catalog/entity/monitoring: false

    # Reorder catalog entity tabs
    - entity-content:catalog/entity/docs:
        config:
          title: Documentation
    - entity-content:catalog/entity/dependencies:
        config:
          title: Component Dependencies
----

== Configure the dynamic home page
[source,yaml]
----
app:
  extensions:
    - page:home:
        config:
          path: /
    - api:home/visits: true
    - app-root-element:home/visit-listener: true
----

== Customize user settings tabs
[source,yaml]
----
app:
  extensions:
    # Reorder user settings tabs
    - settings-tab:user-settings/general: {}
    - settings-tab:user-settings/auth-providers: {}
    - settings-tab:user-settings/feature-flags: {}
----
