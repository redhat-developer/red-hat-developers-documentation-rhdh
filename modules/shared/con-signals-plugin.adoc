= Signals plugin for real-time message delivery

[role="_abstract"]
The Signals plugin provides a real-time delivery channel that backend plugins in {product} ({product-very-short}) use to push messages to the frontend, so users see updates the moment events occur instead of after a polling delay.

Signals is an enabling plugin with no user interface of its own. Other plugins use it to deliver content in real time. The Notifications plugins are the most common consumer: when Signals is enabled, notifications appear instantly in the {product-very-short} header instead of waiting for the next polling interval.

Plugins integrate with Signals in one of two ways:

* The Signals hook, which frontend code uses to subscribe to messages on a topic.
* The Signals API, which backend code uses to publish messages to subscribers.

[NOTE]
====
Signals is a {generally-available} plugin. Enabling it does not change the availability or support status of the plugins that consume it. To confirm the support status of any plugin, including Signals and the Notifications plugins, see the plugin tables in the {dynamic-plugins-reference-book-link}[{dynamic-plugins-reference-book-title}].
====
