. Remove the `auth.providers.guest` entry from the `{my-app-config-file}` file, or set `disabled` to `true` for the guest authentication provider dynamic plugin in your `dynamic-plugins.yaml` file.
For more information about the `disabled` parameter, see {installing-and-viewing-plugins-book-link}#installing-dynamic-plugins-using-the-helm-chart_install-dynamic-plugins-in-rhdh[Installing dynamic plugins using the Helm chart].
. In the `{my-app-config-file}` file, set the authentication environment to `production` to also hide the guest login option when {product-short} runs in production mode:
+
[source,yaml]
----
auth:
  environment: production
----
