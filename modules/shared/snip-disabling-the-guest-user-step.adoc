. Remove the `auth.providers.guest` entry from the `{my-app-config-file}` file, or set `enabled` to `false` for the guest authentication provider dynamic plugin in your `dynamic-plugins.yaml` file.
For more information about the `enabled` parameter, see {installing-and-viewing-plugins-book-link}#installing-dynamic-plugins-using-the-helm-chart_install-dynamic-plugins-in-rhdh[Installing dynamic plugins using the Helm chart].
+
[NOTE]
====
Guest login is also hidden automatically when {product-short} runs with the `NODE_ENV` environment variable set to `production`, which production deployments set by default.
This is determined by `NODE_ENV`, not by `auth.environment`.
To reliably prevent guest login regardless of environment, remove the entry or disable the plugin as shown in this step.
====
