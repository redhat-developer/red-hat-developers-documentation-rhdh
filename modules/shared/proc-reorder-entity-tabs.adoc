[id="reorder-entity-tabs_{context}"]
= Change the order of tabs on entity pages

[role="_abstract"]
Reorder entity page tabs to prioritize the information your teams use most frequently.
Tabs appear in the order they are listed in the `app.extensions` section of your `{my-app-config-file}` file.

.Prerequisites

* {product} {product-version} or later is installed with the new front-end system enabled.
* You have access to modify your `{my-app-config-file}` file.

.Procedure

. Identify the extension IDs for the tabs you want to reorder.
+
Common entity content extension IDs include:
+
[cols="1,2", options="header"]
|===
|Extension ID
|Tab name

|`entity-content:catalog/entity/overview`
|Overview

|`entity-content:catalog/entity/docs`
|Docs

|`entity-content:catalog/entity/dependencies`
|Dependencies

|`entity-content:catalog/entity/ci`
|CI

|`entity-content:catalog/entity/cd`
|CD

|`entity-content:catalog/entity/kubernetes`
|Kubernetes

|`entity-content:catalog/entity/topology`
|Topology

|`entity-content:catalog/entity/api`
|API

|`entity-content:catalog/entity/definition`
|Definition

|`entity-content:catalog/entity/monitoring`
|Monitoring
|===

. Edit your `{my-app-config-file}` file and list the entity content extensions in your desired order:
+
[source,yaml]
----
app:
  extensions:
    # Entity tabs appear in this order
    - entity-content:catalog/entity/overview:
        config:
          title: Overview
    - entity-content:catalog/entity/docs:
        config:
          title: Documentation
    - entity-content:catalog/entity/dependencies:
        config:
          title: Dependencies
    - entity-content:catalog/entity/kubernetes:
        config:
          title: Kubernetes
    - entity-content:catalog/entity/ci:
        config:
          title: CI/CD
----
+
Extensions appear on entity pages in the order listed in the configuration file.

. To move a specific tab to a higher priority position, list it earlier in the `app.extensions` section:
+
== Prioritize documentation
[source,yaml]
----
app:
  extensions:
    # Documentation tab appears first
    - entity-content:catalog/entity/docs:
        config:
          title: Documentation
    # Overview tab appears second
    - entity-content:catalog/entity/overview:
        config:
          title: Overview
----

. To group related tabs together, list them consecutively:
+
== Group development-related tabs
[source,yaml]
----
app:
  extensions:
    - entity-content:catalog/entity/overview: {}
    # Development tabs grouped together
    - entity-content:catalog/entity/ci: {}
    - entity-content:catalog/entity/cd: {}
    - entity-content:catalog/entity/dependencies: {}
    # Documentation and reference tabs grouped together
    - entity-content:catalog/entity/docs: {}
    - entity-content:catalog/entity/api: {}
    - entity-content:catalog/entity/definition: {}
----

. Save the `{my-app-config-file}` file.

. Restart your {product} instance to apply the tab order changes.

.Verification

. Navigate to a catalog entity page in your {product} instance.
. Verify that tabs appear in the order specified in your configuration.
. Check that grouped tabs appear together as expected.

== Prioritize operational tabs for components

To emphasize operational information for component entities:

[source,yaml]
----
app:
  extensions:
    # Operational tabs appear first
    - entity-content:catalog/entity/kubernetes:
        config:
          title: Kubernetes
    - entity-content:catalog/entity/monitoring:
        config:
          title: Monitoring
    - entity-content:catalog/entity/ci:
        config:
          title: Continuous Integration
    - entity-content:catalog/entity/cd:
        config:
          title: Continuous Deployment
    # Development and reference tabs follow
    - entity-content:catalog/entity/overview: {}
    - entity-content:catalog/entity/docs: {}
    - entity-content:catalog/entity/dependencies: {}
----

This configuration places Kubernetes and monitoring information before the standard overview tab.
