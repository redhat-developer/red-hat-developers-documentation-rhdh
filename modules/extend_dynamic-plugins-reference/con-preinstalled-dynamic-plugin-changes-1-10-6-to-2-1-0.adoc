= Preinstalled dynamic plugin changes between 1.10.6 and 2.1.0

[role="_abstract"]
{product} 1.10.6 enables 15 dynamic plugins by default; {product} 2.1.0 enables 19. The following table lists the plugins that are enabled by default in one release but not the other.

"Not in catalog" indicates that the plugin is not shipped in that release at all, rather than being shipped but disabled by default.

[%header,cols="3,1,1,1,1,2"]
|===
|*Plugin package* |*1.10.6 default* |*1.10.6 version* |*2.1.0 default* |*2.1.0 version* |*Change*

|`@red-hat-developer-hub/backstage-plugin-dynamic-home-page` |Enabled |1.13.5 |Not in catalog |n/a |Removed; replaced by `backstage-plugin-homepage`
|`@red-hat-developer-hub/backstage-plugin-global-floating-action-button` |Enabled |1.9.3 |Not in catalog |n/a |Removed
|`@backstage/plugin-org` |Not in catalog |n/a |Enabled |0.7.8 |Added
|`@red-hat-developer-hub/backstage-plugin-app-auth` |Not in catalog |n/a |Enabled |1.2.0 |Added
|`@red-hat-developer-hub/backstage-plugin-app-defaults` |Not in catalog |n/a |Enabled |1.12.1 |Added
|`@red-hat-developer-hub/backstage-plugin-app-integrations` |Not in catalog |n/a |Enabled |1.1.1 |Added
|`@red-hat-developer-hub/backstage-plugin-homepage` |Not in catalog |n/a |Enabled |3.1.0 |Added
|`@red-hat-developer-hub/backstage-plugin-homepage-backend` |Disabled |0.1.3 |Enabled |0.6.0 |Promoted to enabled
|===
