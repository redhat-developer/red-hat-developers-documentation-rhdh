= Preinstalled dynamic plugin changes between 1.10.6 and 2.1.0

[role="_abstract"]

"n/a" indicates that the plugin is not shipped in that release at all.

|`@backstage/plugin-org` |n/a |n/a |Enabled |0.7.8 |Added
