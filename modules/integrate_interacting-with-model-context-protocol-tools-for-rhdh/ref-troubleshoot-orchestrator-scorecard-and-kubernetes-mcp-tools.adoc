= Resolve issues with Orchestrator, Scorecard, and Kubernetes MCP tools

[role="_abstract"]
Diagnose and resolve common issues with the Orchestrator, Scorecard, and Kubernetes Model Context Protocol (MCP) tools.

The following table lists common issues and their resolutions:

[cols="1,2", options="header"]
|===
| Issue | Cause and resolution
| `list-workflows` or `list-instances` return unexpectedly large payloads or are slow. | Use the `limit` and `offset` input parameters (default 50, maximum 100) to page through results instead of relying on a single unbounded call.
| Kubernetes tools return no clusters, or `Failed to fetch Kubernetes clusters: 404`. | The Kubernetes plugin (`@backstage/plugin-kubernetes-backend`) is not installed or configured, or has no clusters registered. Verify `kubernetes.clusterLocatorMethods` in your `app-config.yaml` file and that `kubernetes-mcp-extras` is listed under `backend.actions.pluginSources`.
| `get-entity-metrics` throws `NotAllowedError` even though the caller has `scorecard.metric.read`. | The tool also enforces `catalog.entity.read` for the requested `entityRef`. Grant the caller catalog read access to the entity, or verify that the entity reference is correct.
|===
