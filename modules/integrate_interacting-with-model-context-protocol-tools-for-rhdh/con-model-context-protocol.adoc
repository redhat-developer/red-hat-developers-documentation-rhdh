= Connect AI applications to external systems using MCP

[role="_abstract"]
Model Context Protocol (MCP) connects AI applications to external systems, enabling {product-short} MCP tools through the mcp-actions-backend plugin.

include::{docdir}/artifacts/snip-developer-preview-mcp.adoc[]

*Model Context Protocol* (*MCP*) connects AI models and applications (*MCP clients*) to external systems (*MCP servers*) to access information and workflows. *MCP servers* define the tools that MCP clients can interact with. {product} ({product-very-short}) supports MCP tools through the `mcp-actions-backend` plugin available in {backstage} 1.40 or later.

The {product-very-short} MCP server supports any standard MCP-compliant client, including Cursor, Visual Studio Code, and Claude Code. It enforces a Zero Trust security model: every tool call is validated against the authenticated user's {backstage} identity and RBAC permissions, regardless of which client makes the request.

[IMPORTANT]
====
You must verify that your model supports tool calling before you enable Model Context Protocol (MCP) features. Using an incompatible model results in error messages.
====
