= AI Catalog overview

[role="_abstract"]
The AI Catalog provides a marketplace-style interface to browse, search, filter, and discover AI assets registered in the Software Catalog, helping you find agents, skills, MCP servers, AI models, and model servers for your organization.

The AI Catalog is a dynamic front-end plugin that integrates with {product-short} to give developers a dedicated discovery interface for AI capabilities. Instead of searching across multiple registries, repositories, and documentation sources, developers use a single catalog with category grouping, contextual filtering, and download actions.

The AI Catalog provides the following capabilities:

* *Browse AI assets* -- View all available AI agents, skills, MCP servers, AI models, and model servers in a card-based grid layout
* *Search and filter* -- Find assets by name, description, or tag, and narrow results by category, source connector, or lifecycle
* *View asset details* -- Access complete information about each asset including name, description, versions, source registry, and usage documentation
* *Copy deployment commands* -- For OCI-based assets, copy `docker` or `podman` pull commands directly from the detail page
* *Understand dependencies* -- View version lists and identify the recommended version for each asset

The AI Catalog is a discovery and metadata browsing interface. Version 1 explicitly excludes the following capabilities:

* Install, deploy, or run actions for AI assets
* Ratings, reviews, or usage analytics
* Notifications or alerts for new assets
* In-UI editing or curation of asset metadata

After you find an asset in the AI Catalog, follow the usage documentation or external links to install, configure, and use the asset in your environment.

The AI Catalog integrates with the following {product-short} components:

* *Software Catalog API* -- Retrieves AI Asset entities with required annotations
* *Search infrastructure* -- Enables federated search across AI assets and other catalog entities
* *TechDocs* -- Renders usage documentation when TechDocs references are present on entities
* *Permission Framework* (optional) -- Enforces RBAC visibility policies when configured

The AI Catalog supports the following asset categories:

[cols="1,3",options="header"]
|===
| Category | Description

| AI Agents
| Autonomous AI systems that perform tasks by using tools and skills

| AI Skills
| Reusable capabilities that agents call to accomplish specific tasks

| MCP Servers
| Model Context Protocol servers that expose tools and resources to AI clients

| AI Models
| Machine learning models for inference and prediction

| Model Servers
| Deployment platforms that serve AI models at runtime
|===
