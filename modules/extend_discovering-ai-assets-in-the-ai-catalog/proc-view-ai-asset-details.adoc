= View AI asset details

[role="_abstract"]
To understand what an AI asset does and how to use it, view its detail page showing complete metadata, versions, and usage documentation.

.Prerequisites
* The AI Catalog plugin is enabled in your {product-short} instance.
* You have browsed the AI Catalog and located an asset.

.Procedure
. In the AI Catalog, click an asset card.
+
The asset detail page opens, displaying complete information about the asset.

. Review the *AI Asset Summary* card:
+
* Asset name
* Full description
* Category and type
* Source registry and ingestion connector
* Owner
* Lifecycle status

. Review the *Version List* card:
+
* List of all available versions
* Current or recommended version (highlighted)
* Version history

. Review the *How to use this* panel or *Usage* tab:
+
* If the asset has TechDocs documentation, the panel renders setup instructions, configuration snippets, and usage examples inline.
* If the asset does not have TechDocs, the panel displays links to:
** Source registry entry
** Source repository
** Download or distribution location

. Optional: For OCI-based assets (skills published as container images), copy deployment commands:
.. Locate the *Download/Adopt* card on the detail page.
.. Click *Copy* next to the `docker pull` or `podman pull` command.
.. Paste the command into your terminal to pull the asset image.

.Verification
. The detail page displays the asset name, description, category, versions, and usage documentation or external links.
. For OCI-based assets, the Download/Adopt card shows a complete pull command with registry URL, namespace, image name, and digest.
