= Kubernetes front-end plugin

[role="_abstract"]

Use the Kubernetes front-end plugin to expose information about your entity-specific Kubernetes objects. The plugin provides details about the deployments, pods, and other objects for a service. It also shows identified errors affecting the service.

The plugin directly interfaces with the Kubernetes backend plugin.
