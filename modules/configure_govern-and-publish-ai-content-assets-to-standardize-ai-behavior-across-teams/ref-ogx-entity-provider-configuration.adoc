= OGX entity provider configuration reference

[role="_abstract"]
Use this reference to configure the OGX entity provider under the `ai-catalog.entityProviders.ogx` key in your `{my-app-config-file}` file.

== Provider fields

The following fields configure how the provider connects to the OGX Model Server and how it imports agents.

[cols="1,1,2", options="header"]
|===
| Field | Required | Description

| `baseUrl`
| Yes
| The base URL of the OGX Model Server, for example `https://ogx.apps.example.com`. The provider queries this server for the models that it serves.

| `defaultAgent`
| No
| The `id` of the agent that the AI Catalog uses by default.

| `maxAgentTurns`
| No
| The maximum number of turns that an agent can take in a single interaction.

| `apiKey`
| No
| The API key or token that the provider uses to authenticate to the OGX Model Server. Reference this value from a Kubernetes `Secret`.

| `caData`
| No
| The base64-encoded PEM certificate authority (CA) bundle for the OGX Model Server. Required when the server presents a self-signed or internally signed certificate over HTTPS.

| `skipTLSVerify`
| No
| Whether to skip TLS verification of the OGX Model Server certificate. Set this to `false` in production. The `apiKey`, `caData`, and `skipTLSVerify` fields use the same format as the {backstage} Kubernetes plugin.

| `agents`
| No
| A list of OpenAI Agent SDK compatible agents to import into the catalog as `AiResource` entities with `spec.type: agent`.
|===

== Agent fields

Each entry in the `agents` list defines one agent. The provider imports each agent as an `AiResource` entity with `spec.type: agent`.

[cols="1,1,2", options="header"]
|===
| Field | Required | Description

| `id`
| Yes
| A unique identifier for the agent within the provider configuration.

| `name`
| No
| The display name of the agent.

| `description`
| No
| A short description of the agent's purpose. A clear description improves discoverability in the catalog.

| `instructions`
| No
| The system instructions that define the agent's behavior.

| `handoffs`
| No
| A list of agent `id` values that this agent can transfer control to.

| `handoffDescription`
| No
| A description that other agents use to decide when to transfer control to this agent.

| `enableRAG`
| No
| Whether to enable retrieval-augmented generation (RAG) for the agent.

| `model`
| No
| The model that the agent uses. When omitted, the agent uses the server default.

| `lifecycleStage`
| No
| The lifecycle stage of the agent, for example `published`.

| `createdBy`
| No
| The entity reference of the user who created the agent, for example `user:default/admin`.
|===
