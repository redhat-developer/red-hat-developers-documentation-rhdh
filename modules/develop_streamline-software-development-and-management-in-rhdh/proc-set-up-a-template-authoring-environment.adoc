= Set up a template authoring environment

[role="_abstract"]
To author templates that pass validation on the first attempt, set up a repository with the layout that {product} expects. The `init` command checks your tools, scaffolds a starter template, and creates the root `location.yaml`.

.Prerequisites

* You installed the `rhdh-templates` skill.
* `python3` and `git` are available in your environment.

.Procedure

. Ask your agent to run the `init` command, or run the bundled script directly from your target directory:
+
[source,terminal]
----
python <skill_dir>/scripts/init.py --path .
----
+
Replace `<skill_dir>` with the path to the installed `rhdh-templates` skill.

. Optional: To check connectivity to a running instance, add the `--rhdh-url` flag:
+
[source,terminal]
----
python <skill_dir>/scripts/init.py --path . --rhdh-url https://rhdh.example.com
----

. Review the reported results, including any missing tools, the scaffolded paths, and the connectivity status.

.Verification

. The `templates/` directory exists and has at least one template folder.
. A root `location.yaml` exists with the target `./templates/**/template.yaml`.
. The `init` script exits with code `0` (ready) or `1` (layout created, but optional tools or {product-very-short} are unavailable).

[NOTE]
====
For the recommended development loop, install `djlint` so that local validation can lint Nunjucks in skeleton files. If a running instance is unreachable, local authoring and validation still work.
