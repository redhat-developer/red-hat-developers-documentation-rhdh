= Set up a template authoring environment

[role="_abstract"]
To author templates in the layout that {product} expects, set up a repository first. The `init` command checks your tools, scaffolds a starter template, and creates the root `location.yaml`.

.Prerequisites

* You have installed the `rhdh-templates` skill.
* `git` is available in your environment.

.Procedure

. Ask your agent to run the `init` command from your target directory to check your tools, scaffold the template repository layout, and create the root `location.yaml`.

. Optional: Ask your agent to also check connectivity to a running instance, and provide the instance URL.

. Review the reported results, including any missing tools, the scaffolded paths, and the connectivity status.
+
[NOTE]
====
For the recommended development loop, install `djlint` so that local validation can lint Nunjucks in skeleton files. If a running instance is unreachable, local authoring and validation still work.
====

.Verification

. The `templates/` directory exists and has at least one template folder.
. A root `location.yaml` exists with the target `./templates/**/template.yaml`.
. The `init` script exits with code `0` (ready) or `1` (layout created, but optional tools or {product-very-short} are unavailable).
