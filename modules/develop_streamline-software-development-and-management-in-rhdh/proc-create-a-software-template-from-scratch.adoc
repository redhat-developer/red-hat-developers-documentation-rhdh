= Create a software template from scratch

[role="_abstract"]
When no reference codebase exists, create a software template from scratch with AI guidance on {product} conventions. The `create` workflow gathers your intent, suggests reference examples, and builds a minimal but complete template that passes validation.

.Prerequisites

* You have installed the `rhdh-templates` skill and set up a template repository.

.Procedure

. Ask your agent to create a template. When prompted, provide the golden path the template enables, the target entity type, the required form fields, the steps to include, and your source control provider.

. Review the reference examples that the skill suggests for your stack. You can mirror an example's step sequence or start from the bundled minimal template.

. Confirm that the skill builds the template directory with `template.yaml`, a `skeleton/` directory, and an optional `README.md`. In skeleton files, values use the `${{ values.* }}` prefix, which the `fetch:template` action requires.

. Ask your agent to register the template by generating or updating the root `location.yaml`.

.Verification

. The `template.yaml` is a valid `v1beta3` template with parameters, steps, and outputs appropriate to your use case.
. The `skeleton/` directory has at least one templated file, and `location.yaml` lists the new template.
. Local validation and gotcha checks report zero critical findings. See xref:validate-a-software-template-locally_{context}[Validate a software template locally].
