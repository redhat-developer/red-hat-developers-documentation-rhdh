= Install the rhdh-templates skill

[role="_abstract"]
To give your coding agent {product} template expertise, install the `rhdh-templates` skill from the community skill pack. After installation, the agent loads the skill automatically when you ask it to author or validate a template.

include::{docdir}/artifacts/snip-community-skill-support.adoc[]

.Prerequisites

* You have a supported coding agent installed, such as link:https://docs.anthropic.com/en/docs/claude-code/getting-started[Claude Code], Cursor, or Codex.
* You have Node.js and `npx` available in your environment.

.Procedure

. To install only the `rhdh-templates` skill, run the following command:
+
[source,terminal]
----
npx skills add redhat-developer/rhdh-users-skill-pack --skill rhdh-templates
----
+
To install the full skill pack, omit the `--skill` flag.

. Optional: To target a specific agent, add the `-a` flag. For example:
+
[source,terminal]
----
npx skills add redhat-developer/rhdh-users-skill-pack -a claude-code
----

.Verification

. List the available skills without installing them:
+
[source,terminal]
----
npx skills add redhat-developer/rhdh-users-skill-pack --list
----

. In your agent, ask it to use the skill. For example: `Use the rhdh-templates skill to validate my template.yaml`. The agent loads the skill and prompts you for the next step.
