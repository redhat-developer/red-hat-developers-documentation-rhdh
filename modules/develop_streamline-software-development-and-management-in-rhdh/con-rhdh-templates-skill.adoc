= The rhdh-templates skill for AI-assisted authoring

[role="_abstract"]
To author correct golden-path {product} ({product-very-short}) software templates without trial and error, use the `rhdh-templates` skill. The skill encodes Scaffolder conventions, common gotchas, and parameter widgets so that new adopters produce convention-compliant templates.

include::{docdir}/artifacts/snip-community-skill-support.adoc[]

The `rhdh-templates` skill is a community agent skill in the `rhdh-users-skill-pack` repository. It works with Claude Code, Cursor, Codex, and many other coding agents. You describe your goal in plain language, and the skill guides you through authoring and validating a {product} software template.

A software template is a `kind: Template` entity that the Scaffolder processes. Each template combines the following artifacts:

* `template.yaml`: metadata, the parameter form (`spec.parameters`), the actions to run (`spec.steps`), and outputs (`spec.output`).
* `skeleton/`: the files copied into the generated repository, with Nunjucks placeholders in place of substituted values.
* `location.yaml`: a `kind: Location` entity at the repository root that registers your templates for catalog import.

The skill lowers the learning curve by encoding {product-very-short} conventions, common gotchas, and parameter widgets, and by validating templates before they reach a running instance. With AI guidance, you can convert an existing codebase into a parameterized template, author a template from scratch, add parameters, steps, and skeleton files incrementally, and validate a template locally before you confirm Scaffolder execution against a running instance.
