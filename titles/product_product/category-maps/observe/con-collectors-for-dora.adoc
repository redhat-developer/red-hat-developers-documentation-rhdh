= Collectors for DORA

[role="_abstract"]
Implement custom DORA collectors to integrate deployment and incident data from systems other than GitHub and Jira. Custom collectors enable DORA metrics for GitLab, PagerDuty, Azure DevOps, or proprietary platforms.

== Understanding collector contracts

The DORA backend module defines three collector types, each with a specific contract that custom implementations must fulfill:

Deployment collector::
Identifies production deployments with timestamps, commit SHAs, and environment information. Used by Deployment Frequency, Lead Time for Changes, and Change Failure Rate metrics.

Deployment pull request collector::
Resolves the pull requests or merge requests that contributed code between two deployment SHAs. Used by Lead Time for Changes to measure the time from first commit to deployment.

Incident collector::
Tracks service degradations with created and resolved timestamps. Used by Change Failure Rate and Time to Restore Service metrics.

Each collector type has a defined input/output contract. Custom implementations must follow these contracts to ensure compatibility with DORA metric calculations.
