= Migrate from {product-very-short} 1.x to 2.1

[role="_abstract"]
Migrate a {product} instance from version 1.x to version 2.1. Version 2.1 introduces breaking changes to Helm charts, custom plugins, RBAC policies, AI assistant settings, container images, and plugin distribution, grouped into a phased migration workflow.
