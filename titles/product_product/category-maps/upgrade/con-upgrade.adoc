= Upgrade

[role="_abstract"]
Keep your {product} instance current by upgrading to the latest version to receive new features, security patches, and bug fixes.

[IMPORTANT]
====
{product-very-short} 2.1 introduces breaking changes that are not backward compatible, including a standalone Helm chart, the removal of bundled plugin wrappers, renamed container images, and renamed RBAC permissions. If you are moving from version 1.x to version 2.1, follow link:{migrating-book-link}[{migrating-book-title}] for the required migration steps before you upgrade.
====
