= Custom dynamic plugins for specialized workflows

[role="_abstract"]
Develop custom plugins for the new front-end system (NFS) when standard plugins do not meet organizational requirements. Add extension blueprints to the plugin's `createFrontendPlugin` extensions, then use the {product-very-short} 2.1 CLI to export, test, and package the plugin.
