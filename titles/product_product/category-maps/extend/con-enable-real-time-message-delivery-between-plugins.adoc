= Enable real-time message delivery between plugins

[role="_abstract"]
Deliver updates to users the moment events occur in {product} by enabling the Signals plugin, a shared real-time messaging channel that other plugins use to push content to the frontend without waiting for a polling interval.

Enabling Signals benefits any plugin that supports it, such as Notifications, by replacing periodic polling with instant delivery. Start by understanding what Signals does and how plugins integrate with it, then enable the frontend and backend plugins.
