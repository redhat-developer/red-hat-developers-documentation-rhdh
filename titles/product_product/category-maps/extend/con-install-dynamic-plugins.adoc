= Dynamic plugin installation

[role="_abstract"]
Install dynamic plugins through the Operator or Helm chart to add capabilities to {product}. In {product} 2.1, the application discovers new front-end system (NFS) extensions from installed plugins by default. `dynamicPlugins.frontend` does not register routes or components.
