= Local development and testing of plugin components

[role="_abstract"]
Create a version-pinned plugin for the new front-end system (NFS) with the {product-very-short} 2.1 CLI. Use its development harness to inspect the page and {product-local-very-short} to verify an exported plugin with Catalog entities.
