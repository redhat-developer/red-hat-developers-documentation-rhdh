= Extension-based front-end plugins

[role="_abstract"]
In {product} 2.1, installed front-end plugins contribute pages, navigation, icons, and APIs through extension blueprints. The application discovers these extensions automatically.

Plugin developers define extension blueprints in the plugin's `createFrontendPlugin` extensions. Administrators use `app.extensions` in `{my-app-config-file}` only to disable, reorder, or customize them. For configuration mappings, see {configuring-book-link}#configuration-key-mapping-from-old-to-new-front-end-system_migrate-to-the-front-end-system-to-use-blueprint-based-dynamic-routing[Configuration key mapping from old to new front-end system].
