= NFS plugin export and packaging

[role="_abstract"]
Export a custom plugin for the new front-end system (NFS) by using the {product-very-short} 2.1 CLI. Package it as an OCI image. The Dynamic Plugin Factory can automate this work for several plugins.

Existing front-end plugins must migrate to extension blueprints before export for {product} 2.1.
