= Old front-end system: specialized front-end extensions for APIs and features

[role="_abstract"]
In the old front-end system (OFS), YAML wiring configured specialized front-end features. The `dynamicPlugins.frontend` configuration does not apply to {product} 2.1.

The new front-end system discovers extensions from installed plugins. Administrators configure only extensions that need overrides, while plugin developers define blueprints in code. For details, see {configuring-book-link}#configuration-key-mapping-from-old-to-new-front-end-system_migrate-to-the-front-end-system-to-use-blueprint-based-dynamic-routing[Configuration key mapping from old to new front-end system] and {configuring-book-link}#migrate-custom-plugins-to-ensure-compatibility-after-upgrade_migrate-to-the-front-end-system-to-use-blueprint-based-dynamic-routing[Migrate custom plugins to ensure compatibility after upgrade].
