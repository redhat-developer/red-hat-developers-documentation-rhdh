= Provide organization context to the {ia-short} with Agent Skills

:context: provide-organization-context-with-agent-skills

[role="_abstract"]
Use Agent Skills to provide the {ia-short} with organization-specific instructions and reference material. The {ia-short} loads skills from the `lightspeed-core` container file system when it starts.

Use Agent Skills to achieve the following goals:

`Apply your development standards`:: Guide the {ia-short} to recommend your approved libraries, patterns, and coding conventions.
`Standardize troubleshooting`:: Give developers consistent, organization-approved answers to common errors and operational issues.
`Share approved workflows`:: Ground responses in your operational procedures so that developers follow the same steps across teams.
