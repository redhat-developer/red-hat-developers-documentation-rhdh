= Manage plugin catalog sources

:context: manage-plugin-catalog-sources




[role="_abstract"]
Configure which plugin catalog index images {product} extracts to populate the Extensions UI.
Separate certified Red Hat plugins from community, partner, or internal custom plugin sources to enable plugin discovery while maintaining governance over plugin installation.

== Prerequisites

* You have deployed or are preparing to deploy {product} using the Helm chart, Operator, or {product-local}.
* You have access to the catalog index image registries you want to configure.
