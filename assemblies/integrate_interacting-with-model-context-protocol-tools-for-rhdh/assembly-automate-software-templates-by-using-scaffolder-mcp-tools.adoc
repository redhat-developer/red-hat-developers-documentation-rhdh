= Automate Software Templates by using Scaffolder MCP tools
:context: automate-software-templates-by-using-scaffolder-mcp-tools

[role="_abstract"]
Use the Scaffolder Model Context Protocol (MCP) (`scaffolder-mcp-extras`) tools to query available actions, validate template dry-runs, and retrieve task logs during Software Template development in {product-very-short}.

These tools use provided credentials and adhere to existing role-based access control (RBAC) permissions.

[IMPORTANT]
====
All operations performed through Scaffolder MCP tools use the `On Behalf Of the User` (OBOU) security model. The server resolves the bearer token from the MCP client to the calling user's {backstage} identity and calls the `PermissionEvaluator` before executing any action. If the user does not have the required `scaffolder.action.execute` permission, the tool returns an `Unauthorized` error without performing any action. The MCP server never uses a privileged system token to substitute for the user's credentials. This model maintains a consistent audit trail and ensures that all Scaffolder operations respect your configured RBAC policies.
====
